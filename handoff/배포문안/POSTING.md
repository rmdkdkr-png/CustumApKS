# NGPcustumSP 코어 v1.0.2 — 레트로아크용

네오지오 포켓 컬러 『사무라이 쇼다운!2』에 **한국어 해설 · 원버튼 필살기 · 일러스트 기둥**을
얹는 Beetle NeoPop 포크 코어입니다. 안드로이드 앱판과 기능이 같습니다.

레트로아크가 도는 곳이면 됩니다 — 폰, 스팀덱, PC, 휴대용 게임기.

[여기에 사진 — 03_fight1.png]

## 받는 법 — 기기에 맞는 것 하나만

| 쓰시는 기기 | 파일 |
|---|---|
| **안드로이드 폰·태블릿** (요즘 기기 대부분) | `…-android-arm64-v8a.so` |
| 안드로이드 (오래된 32비트) | `…-android-armeabi-v7a.so` |
| 안드로이드 (에뮬레이터·일부 태블릿) | `…-android-x86_64.so` / `…-android-x86.so` |
| 안드로이드 (RISC-V) | `…-android-riscv64.so` |
| 리눅스 PC · 스팀덱 | `…-linux-x86_64.so` |

## 넣는 법 (안드로이드)

파일 관리자를 만지실 필요 없습니다.

1. 받은 `.so` 를 폰의 **다운로드** 폴더에 둡니다
2. 레트로아크 → **Load Core** → **Install or Restore a Core**
3. 목록에서 그 파일을 고릅니다. 끝입니다

## 버튼

| 패드 | 하는 일 |
|---|---|
| B (아래) | **A** — 베기 |
| A (오른쪽) | **B** — 발차기 |
| **X** 또는 **R** | **SP** — 원버튼 필살기 (방향과 같이) |
| **Y** 또는 **L** | **A+B 동시** (뒤를 잡고 누르면 **비오의**) |

**한국어 해설 15인**, **원버튼 필살기**, **양옆 일러스트 기둥** 세 가지가 핵심입니다.

[여기에 사진 — collage.png]

**해설** — 하오마루부터 유가까지 15명이 각자 말투로 경기를 읽습니다.
대사 4,200여 줄이고 상대 이름을 부릅니다. 심판 쿠로코가 판정을 외칩니다.

**원버튼 필살기** — 사쇼!2 는 커맨드 판정이 인색해서 제대로 넣어도 엉뚱한 게 나가곤 합니다.
롬을 뜯어보니 판정 루틴이 입력 기록을 거꾸로 훑으면서 안 맞는 입력을 건너뛰더군요.
그래서 직전 입력 찌꺼기가 남아 있으면 짧은 커맨드가 긴 커맨드를 가로챕니다.
버튼을 누른 프레임에 게임 자신의 리셋 경로로 입력 기록을 정리하고,
캐릭터·유파에 맞는 커맨드를 보는 방향에 맞춰 뒤집어 넣습니다.
**없는 기술을 만들거나 데이터를 고치지 않고 입력만 대신 넣습니다.**
어느 기술을 어느 방향에 둘지는 게임 안에서 직접 배치하실 수 있습니다.

**일러스트 기둥** — 좌우에 상대 카드 일러가 서고, 맞으면 흔들리고 몰리면 붉어지고
KO 나면 흑백이 됩니다. 그림은 **앱에 안 들어 있습니다** — 타일 주소표만 들고 있고
실행 중에 여러분 롬에서 그 자리에서 굽습니다.

- **레트로아크 코어** — 안드로이드 5종 + 리눅스, 이미 레트로아크 쓰시면 이쪽
