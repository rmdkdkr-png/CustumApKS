# SS2 리그·연습 «둘 다» — 실행 창 옵션 하나 + 타이틀 셋째 줄 ◀▶ (Legacito 시험판 내부 136·137)

요청(2026-10-15):
> 인터페이스등 검수및 수정해줘봐 / 리그 연습모드는 옵션만 넣고 되는걸로 해줘 둘중 택일말고 둘다 되게 /
> 3번째에서 화살표넣고 좌우해서 하든 칸을 만들든 / 기타 글씨나 메뉴등 수정할만한거있으면 레퍼런스 공부해서 해줘봐

그 전에는 실행 창 맨 아래 링크 둘(«연습 대전으로 ›» · «가상 리그 (시험) — 게임 속 「리그 대전」으로 ›») 중 하나를 골라 들어가야 했고,
한 판에는 연습 아니면 리그 하나만 있었다.

## 바뀐 것

## 구현

- **native `league.c`** — 허브에 `dual · sel · handoff · focus · menu_saved/menu_orig/row_orig` (H 끝에 붙임).
  - `league_hub_dual(on)` · `league_hub_dual_status(v[5])`(둘 다 · 보이는 종류 · 갈아타기 요청 · 셋째 줄 커서 · 이 판 종류) ·
    `league_hub_handoff_clear()` · `league_hub_go()`(리그 판 바로 상대 선택) · `league_hub_return(-2)`(다른 상대).
  - H_TITLE: 커서가 셋째 줄이면 ←→ 를 게임 대신 받아 `sel` 을 바꾸고(게임은 이 메뉴에서 좌우를 안 씀), A 는 `sel == kind` 면 예전 흐름,
    아니면 `handoff = 1 + sel` 을 세우고 A·B·↑↓ 를 막은 채 기다린다. 커서가 떠나면 `sel = kind`.
  - 화살표: 빈 타일 **0x12E(◀)·0x12F(▶)** — 롬 다섯 판(한글 동봉·v1.01·h1 v1.01·순정·순정 h1)의 부팅·타이틀 내내 안 쓰임(실측).
    한글판은 글자 앞뒤 빈칸 6·12칸(0x1B0), 순정판은 게임 커서 스프라이트(4칸)와 안 겹치게 글자를 6칸부터 쓰고 ◀ 5칸 · ▶ 글자 뒤(«◀PRACTICE▶» 5~14칸).
    칠은 메뉴 글자와 같은 잉크 1 · 바탕 3. 타이틀을 떠나면 두 타일을 비운다.
  - 상태 저장 직전(`league_hub_before_save`)에 셋째 줄 원래 그림·칸을 되돌린다(`menu_restore` — 보관 못 한 앞 판 상태라도 화살표 칸은 비움).
  - 연습 이어하기 덩어리(.prac): H 가 72바이트 커졌다 — 앞 판(636바이트)도 받아 새 칸을 0으로 채운다. 불러온 허브는 `dual` 을 지금 판 값으로 둔다.
- **Java** — `Settings` 항목 «리그·연습» · `LaunchSheet` 링크 정리 · `EmuActivity`: `practiceSetup`(옵션·롬 판 확인·`nativeHubDual`) ·
  `practicePoll`/`hubTick`(갈아타기 요청 → `switchSession`, 못 받으면 `nativeHubHandoffClear`) · `switchSession`(GL 스레드에서 오토세이브·코어 내림 → 새 창) ·
  `hubBlockedBack`(일반 판에서 갈아타 왔는데 리그를 못 열면 원래 게임으로 — `EXTRA_FROM_GAME`, 순위표에서 열었으면 예전처럼 순위표로) ·
  `pocketcore_ss2_practice_ok_<롬 파일>`(일반 판에서 연습이 켜졌는지 — 조작 패치 등으로 안 켜지는 롬이면 리그 판 셋째 줄은 리그만, 그때 한 번 알림) ·
  못 켜는 롬 알림은 롬 판마다 한 번(`pocketcore_ss2_hub_warned`) · 리그 기록을 못 쓰면 셋째 줄은 연습만(한 번 알림) ·
  리셋 뒤 바로 상대 선택으로 가는 동안 띠 «상대 선택으로…»(아니면 «타이틀로…») · 이어하기 실패 창 «멈춘 리그 경기를 이어할 수 없어요»(일반 판에서 왔으면 «게임으로» 단추도).
- 연습 메뉴 글자는 `stage1/practice_glyphs.py`(ROWS)로 다시 만든 `practice_glyphs.h`.

검토: 바뀐 코드를 세 관점(native 상태 기계 · Java 수명 주기 · 사용자 글)으로 검토하는 워크플로를 돌려 나온 것 중 실제인 것을 고쳤다 —
조작 패치 롬에서 리그 판이 «연습 대전»을 내놓던 것, 순위표에서 연 리그가 막히면 일반 게임으로 보내던 것, 앱이 못 받은 갈아타기 요청이 메뉴를 멈추던 것,
불러온 연습 상태가 «둘 다» 값을 덮던 것, 커서가 떠난 뒤에도 셋째 줄이 다른 모드로 남던 것, 앞 판 타이틀 상태·.prac 호환, «지금 자리» 이름, «다른 상대» 띠 글.

## 레퍼런스·검수

워크플로 두 갈래(웹 레퍼런스 조사 21건 · 코드 속 글자·배치 검수 31건)의 제안 중 위 표에 든 것을 반영했다. 근거 요약:
KOF XV 공식 웹매뉴얼(일시정지 «다시 시작», 위치 리셋 왼쪽/중앙/오른쪽), 철권8(연습·재시작·표시 설정 묶음, «[BACK]+[←] 벽을 등지고»),
SF6(리셋+방향 · 랭크 LP 가 상대 등급에 따라 다르게 오름 · 커뮤니티의 «더미 설정»), 3rd Strike(«DAMAGE»), GGST(«첫 타 뒤 가드»),
가로 선택기 관례(돌아가는 목록엔 양옆 화살표). 웹 원문 대조는 프록시 때문에 못 했고 검색 요약으로만 확인했다.

미룬 것(다음에): 연습 메뉴 값 양옆 ◀▶(창을 16칸으로 넓혀야 함) · 메뉴 줄 순서 바꾸기(시험 스크립트가 줄 번호로 움직임) ·
가드 «첫 타 뒤» 표기 · 패드 메뉴 «리셋»(전원) ↔ 연습 «리셋»(자리) 이름 겹침 · 순위표 화면 규칙 글 접기 · 내 캐릭터 화면 띠를 캐릭터/검질/카드 화면별로.
