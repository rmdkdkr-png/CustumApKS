# SS2 연습 대전 1단계 — 게임 속 연습 모드 MVP (Legacito)

요청: «이거하는김에 프랙티스 모드도 다음츠로직트로 만들어줘» (가상 리그를 «실기 느낌으로» 만들던 흐름 그대로).
설계: `0단계_조사설계.md` (램 주소·설계·열린 문제 O-*·확인할 것 P-*).

가상 리그 3단계와 같은 방식으로 **게임 화면 자체**에 넣었다. 일반 세션의 타이틀 메뉴 셋째 줄(원래 «2 인 대전» / «VS PLAY»)이
**«연습 대전» / «PRACTICE»** 가 되고, 그걸 고르면 캐릭터 고르기 화면이 **«상대 선택»**(더미 고르기)으로 바뀐다.
경기는 1인 대전 첫 경기를 «끝나지 않는 연습 경기»로 바꾼 것이고, **연습 메뉴는 게임 일시정지(PAUSE) 위에 게임 글꼴 창으로** 뜬다.

## 해 보는 법

1. (내부 136부터는 실행 창 링크 대신 옵션 «리그·연습» — `2단계_리그연습_하나로.md`) 시험판 설치 → 런처 사무쇼2 카드 → 실행 창 아래 **«연습 대전으로 ›»**. 로고·인트로를 넘겨 **상대 선택**까지 저절로 간다
   (자동 저장이 있어도 이 링크로 열면 이어하기 대신 처음부터 — 자동 저장 파일은 그대로 남는다).
   평소처럼 «시작»으로 열어도 타이틀 셋째 줄이 «연습 대전»이다.
2. **상대 선택**: 15명 모두(가운데 칸 = 유가). **A = 수라 더미 · B = 나찰 더미 · 옵션 = 스테이지**(오른쪽 세로 칸 — 무작위 → 0~7).
   싸우지 않는 CPU 대진 6가지(소게츠 수라·나코루루/리무루루/한조/모로즈미/주베이 나찰)도 고를 수 있지만 더미 «CPU» 는 못 고른다.
3. **내 캐릭터·검질**: 원래 게임 그대로. 옵션 = 컬러, A = 결정, B = 2P색으로 결정(리그와 같음). 이야기·대사는 저절로 넘긴다(카드는 내가 고름).
4. **경기**: 시간 ∞ · 체력은 64 밑으로 안 내려가고 40프레임 쉬면 다시 참 · 상대 이름 «COM» → «2P» · 대미지 숫자(HUD 셋째 줄 가운데, 게임 숫자 타일).
5. **연습 메뉴**: Option 을 짧게 눌렀다 떼면 게임이 멈추고 그 위에 창(10줄). ↑↓ 줄 · ←→ 값 · A 실행 · B·Option 닫기.

   | 줄 | 값 |
   |---|---|
   | 더미 | 서기 · CPU |
   | 가드 | 안 함 · 전부 · 첫 타 뒤 · 랜덤 |
   | 내 분노 / 상대 분노 | 보통 · MAX(진짜 MAX 비트 + 타이머 유지) |
   | 리셋 위치 | 가운데 · 왼쪽 벽 · 오른쪽 벽 · 지난 위치(이 값을 고른 순간 두 사람 자리) |
   | 리셋 좌우 | 그대로 · 바꿈 |
   | 숫자 | 대미지 · 끔 |
   | 지금 리셋 / 다시 고르기 / 타이틀로 | 실행 |

6. **경기 중 리셋**: Option+↓ = 지금 설정 위치로 · Option+←/↑/→ = 왼쪽 벽/가운데/오른쪽 벽으로(설정도 바꿈). 누르는 동안 방향·A·B 는 게임에 안 간다.
7. 화면 아래 띠는 버튼 안내만(정보는 게임 화면 안). 가로 화면에서 띠가 게임 그림 위로 올라가는 자리면 경기 중엔 숨긴다.

## 게임 화면을 어떻게 바꾸나 (요점)

- 타이틀 셋째 줄: 한글판은 게임 메뉴 글자 그림 두 칸(0x1BB·0x1BC)을 «연습 대전»으로, 순정판은 «PRACTICE»(메뉴 창이 12칸까지라 8자가 들어감).
  리그 세션은 «리그 대전»/«LEAGUE» 그대로.
- 연습 메뉴 창: 게임이 «PAUSE» 를 다 그린 뒤 첫째 판에 그린다. 게임이 틱마다 화면 가운데를 두 띠(0x41F5 = 0/0x78) 사이에서 번갈아 보여 주므로
  **두 띠에 모두** 그리고(한 띠면 15Hz 로 깜빡였다), 효과 층 가로 스크롤(0x41F8)은 창이 열린 동안 0. 타일은 열 때마다 «지금 아무 데서도 안 쓰는»
  것만 빌리고(필살 효과가 0x0D8~0x105 를 실제로 씀 — P-15), 팔레트도 첫째 판이 안 쓰는 둘을 고른다. 닫을 때 문자 램·두 판·스프라이트·팔레트를
  바이트까지 되돌리고 Option 을 대신 눌러 일시정지를 푼다.
- 상태 저장 직전엔 우리가 그린 것(창·숫자·«2P»·머리말·세로 칸)을 되돌리고 다음 프레임에 다시 그린다.

## 1단계 검수에서 고친 것 (에이전트 구현 뒤)

리뷰 워크플로(5 관점 · 관점마다 반박 검증, 확인 14건 · 반박 4건) + 안드로이드 에뮬레이터 실기에서:

| 무엇 | 어떻게 |
|---|---|
| **120Hz 폰에서 연습·리그 허브가 두 배로 돎** — 코어가 2배 출력 중이면 retro_run 두 번에 한 번은 합성(에뮬레이션·입력 읽기 없음)인데 그때도 틱이 돌아 회복 40·되풀이·리셋 기다림이 반으로 줄고 대신 누름이 게임이 읽기 전에 바뀜 | c_run 직전 `retro_ngp_fg_state` 로 합성 차례를 보고 진짜 프레임 뒤에만 돌림(리그 허브도 같이 고쳐짐). 호스트 하네스는 120Hz 를 안 받아 합성 호출이 없었다(fg_active 0 확인) |
| **옵션 하나만 바꿔도 연습이 꺼짐** — 앱은 옵션을 바꾸면 저장 → 코어 내림 → 다시 올림 → 불러오기(applyLive). 이어하기·슬롯 불러오기·되돌리기도 같은 길이라 시간 ∞·가만히 선 더미만 남았다(설계 O-13) | 상태 저장 옆 `<경로>.prac`(허브·연습 설정 + 상태 크기·지문). 불러올 때 지문이 맞으면 연습 경기로 되돌림. 연습 경기 밖에서 저장하면 지운다. `t_resume.py` 12/12, 실기(슬롯 저장·불러오기, 보간 120→60Hz 적용하고 이어하기 → 연습 메뉴 그대로) |
| **배경음악(사무쇼1)을 심은 사본에선 연습이 안 켜짐** — 앱 기본이 «SS1 음악»이라 SS1 롬이 있는 사람은 늘 꺼짐 | 사본을 구울 때 «심기 전 md5»를 `.base` 에 남기고, 심기 전 판이 실측한 판이면 켬. 배경음악은 빈칸의 소리 자료와 조립 코드 즉시값만 바꿔 게임 램 배치는 그대로 — **배경음악 끔 사본 롬 6판에서 `t_practice` 68/68**(최신 코어). 수동·조작 패치가 든 사본은 그대로 꺼짐 |
| **자동 저장이 있으면 «연습 대전으로 ›» 링크가 지난 자리로 이어함** | 링크로 막 연 판은 자동 저장 이어하기를 건너뜀(실기 확인) |
| 방향을 쥔 채(앉아 막기) 연 메뉴에서 18프레임 뒤부터 줄이 내려가며 설정이 바뀜 | 열 때 쥐고 있던 방향은 뗄 때까지 안 침(`t_fix1.py`) |
| Option 과 같은 프레임에 누른 방향·A 가 한 프레임 게임에 감 | 입력 콜백에서 Option 이 눌려 있으면 그 프레임부터 막음(`practice_opt_mask`, `t_fix1.py`) |
| «지난 위치»가 다음 경기에선 자리 없이 가운데로 | 고른 자리를 설정에 두어 다음 경기·불러오기에도 남음 |
| 가로 화면에서 띠가 체력 막대를 연습 내내 가림 · 연습이 꺼져도 띠가 남음 | 경기 중엔 겹치면 숨김 · 꺼질 때 내림 |

반박된 것: 시험용 `practice_state_set` 의 창 후보(앱이 안 부름), 이야기 넘기기 A 가 1라운드 첫 틱에 남는다는 것(다음 틱에 이야기 조건이 바로 꺼짐),
md5 만으로 거르는 것 자체(의도된 설계 — 위 배경음악 사본만 넓힘).
