# SS2 가상 리그 3단계 — 게임 속 리그 (Legacito)

요청: «정식 게임 인터페이스마냥 끼워 넣어서 — VS 모드 자리를 고르면 시작하게, 인터페이스를 최대한 우려먹어서. 안드로이드에서 되게 해서 해 봐라.»
덧붙인 요청: «추가했으면 하는 게 1. 컬러 선택 2. 스테이지 선택» → «그 인터페이스는 실기 느낌으로» (아래 «스테이지·컬러 고르기»).

2단계의 랭크전(가상 상대 12명·순위표·상대전적·재대결)을 **게임 화면 자체**로 들여왔다. 리그 화면의 버튼을 누르는 대신,
게임 타이틀 메뉴의 셋째 줄(원래 «2 인 대전» / «VS PLAY»)이 **«리그 대전» / «LEAGUE»** 가 되고, 그걸 고르면 게임의 캐릭터 고르기 화면이
**«상대 선택»** 화면으로 바뀌어 상대를 고른다. 그다음은 원래 게임 그대로(내 캐릭터·검질·카드 → 경기)이고, 결판은 2단계와 똑같이 기록된다.
상대는 모두 게임의 CPU 다(닉네임은 지어낸 이름).

**안드로이드에서 실제로 돌려 봤다**: 이 작업 환경엔 KVM 이 없지만 소프트웨어 CPU(TCG)로 안드로이드 9 에뮬레이터를 띄워(게임 속도 1/15 안팎)
실제 APK 로 타이틀 → 리그 대전 → 상대 선택 → 내 캐릭터 → 경기 → 결과 카드 → 재대결·무효·계속 → 타이틀까지 두 판을 끝까지 해 봤다
(아래 «안드로이드에서 해 본 것»). 그 과정에서 앱의 옛 버그 둘과 이번 코드의 죽는 버그 하나를 찾아 고쳤다.

## 해 보는 법

1. `Legacito-league-s3.apk` 설치(1·2단계 시험판과 같은 패키지·같은 시험 키 — 덮어 설치하면 기록을 잇는다).
2. 런처 사무쇼2 카드 → 실행 창 아래 **「가상 리그 (시험) — 게임 속 「리그 대전」으로 ›」**. (리그 화면의 «게임 속 리그전 ›» 로도 들어간다.)
3. 게임이 켜지면 평소처럼 타이틀 → 메뉴. 셋째 줄이 **«리그 대전»**(순정 롬은 «LEAGUE»). 다른 메뉴는 평소대로 놀 수 있고 기록되지 않는다.
4. «리그 대전»에서 A → 캐릭터 고르기 화면이 **«상대 선택»** 으로 뜬다. 커서를 옮기면 게임 화면 아래 띠에 그 캐릭터를 주캐로 쓰는 가상 상대가 나온다:
   `검은달 · 아수라 나찰 · 어려움 / 3위 · 1080점 · 나와 0승 0패 / A: 도전`. 리그 상대가 없는 캐릭터(소게츠·모로즈미·주베이)는 안 골라진다. **가운데 무작위 칸(게임 속 이름 «쿠로코»)은 숨은 상대 — 고르기 판에 없는 유가(끝판왕)** 자리다.
   상대 고르기 화면이 뜨고 머리말이 «상대 선택»으로 바뀐 뒤의 A 만 받는다(두 번 눌러 안 보고 골라지지 않게).
   **B = 스테이지**: 화면 오른쪽 세로 이름 칸에 스테이지 이름이 게임 글꼴로 나온다(처음엔 커서 상대의 기본 스테이지). B 를 누를 때마다 무작위 → 8개 → 상대 기본.
5. A → 그 상대로 확정. 머리말이 «캐릭터 선택»으로 돌아오고, 같은 화면에서 **내 캐릭터·검질·카드**를 고른다(카드는 올카드).
   **옵션 = 컬러**: 오른쪽 세로 칸이 내 컬러 이름(기본 · 2P색 · 컬러3 · 컬러4)이 되고, 가운데 미리보기 그림이 바로 그 색이 된다(유파 선택에서도).
   **A = 보이는 컬러로 결정, B = 2P색으로 결정**(네오지오 게임처럼 누른 버튼으로 컬러가 갈림).
6. 1인 대전 첫 경기 상대로 고른 상대가 나온다. 2선승 · 라운드 60초 · CPU 난도는 상대 설정대로. 스테이지·컬러는 고른 대로.
7. 결판 → 게임 위 **결과 카드**(최종 승패·점수·순위 변화·상대전적·첫 승·연승) → **재대결**(같은 상대의 내 캐릭터 고르기까지 바로) · **계속**(타이틀 «리그 대전» 칸으로) · **순위표**.
8. 경기 밖에서 뒤로 가기: 계속하기 / 순위표로 나가기 / 타이틀로(이 게임은 캐릭터 고르기에서 뒤로 못 가서 리셋한다). 경기 중 뒤로 가기는 2단계와 같다(이어하기·기권).

## 게임 화면을 어떻게 바꾸나

롬·세이브는 건드리지 않는다. 코어의 **문자 램**(타일 그림 512×16바이트)과 **스크롤 램**(타일 번호표)만 매 프레임 고친다
(코어가 내보내는 `retro_ngp_charram` / `retro_ngp_scrollram`, main 코어·앱 동봉 코어 모두 있음). 배치가 다르면(알 수 없는 롬) 글자는 두고 흐름만 같다.

| 자리 | 한글판(한글패치 v1.01·앱 동봉판) | 순정판(일본어·영어) |
|---|---|---|
| 타이틀 메뉴 셋째 줄 | «2 인 대전» 은 전용 타일 0x1BB~0x1BF — «2 인» 두 타일(0x1BB·0x1BC) 그림을 «리그» 로 | «VS PLAY» 는 글자마다 타일 — 둘째 판 14줄 5~11칸의 타일 번호를 메뉴의 다른 글자(L·A=PLAY, E=COLLECTION·GAME, G=GAME, U=SURVIVAL)로 바꿔 «LEAGUE» |
| 메뉴가 떠 있나 | 둘째 판 12·13·16줄 7칸이 0x1B1·0x1B6·0x1C6 | 12·13·15줄 5칸이 0x1B1·0x1B7·0x1C5 |
| 캐릭터 고르기 머리말 | «캐릭터 선택»(0줄 5~14칸 0x150~, 1줄 0x15A~) — 앞 6칸 × 2줄 «캐릭터» → «상대» | «十五士選択»(1줄 14칸이 0x163) — 열 칸 × 2줄 모두 «상대 선택» |

- 글자 타일은 `stage3/hub_glyphs.py` 로 그렸다(메뉴 글꼴 7px · 머리말 16px 테두리 글꼴, 원래 칠과 같은 색 번호). 머리말은 원래 타일을 보관했다가 상대를 고르면 되돌린다.
- 메뉴 «리그 대전» 칸(커서 램 0x624B = 2)에서 사용자의 A 는 게임에 안 준다. 허브가 커서를 0(1인 대전)으로 바꾸고 A 를 대신 눌러 1인 대전 캐릭터 고르기로 들어간다.
- 상대 고르기 동안 A 는 허브가 받는다(게임은 커서 이동만 본다). 커서 캐릭터 = 0x4E3C ÷ 4(무작위 칸 «쿠로코»는 15 → 유가 14 로 읽는다 — 유가는 1인 대전 고르기 판에 없어서, 2단계 명단의 끝판왕이 게임 속에선 이 칸에 숨어 있다). 상대를 고르는 A 는 사용자가 뗄 때까지 게임에 안 넘긴다(누른 채로 넘어가 내 캐릭터로 바로 골라지지 않게).
- 결판 뒤: 리셋 → 허브가 로고·인트로에서만 A 를 대신 누르고(메뉴가 보이면 멈춤), 메뉴 커서를 «리그 대전»까지 두 칸 내린다. 재대결이면 그대로 같은 상대로 무장하고 1인 대전 캐릭터 고르기까지.
- 이 게임은 캐릭터 고르기에서 B·옵션으로 나갈 수 없다(실측) — 상대 고르기를 그만두면 리셋해서 타이틀로.
- 허브는 그 게임 화면 동안만 켜진다: 코어를 올리고 내릴 때마다 끄고, 허브로 연 화면만 로드 뒤에 다시 켠다(나간 뒤 평소 게임에 메뉴 글자·올카드가 새지 않게).
- «타이틀로»(결과 카드·뒤로 가기)는 리셋을 GL 스레드에서 하므로, 코어가 그 리셋을 받을 때까지(돌려보낸 횟수 — 허브 상태 9번째 값) Java 는 옛 상태로 아무것도 하지 않는다.
  상대만 고르고 대진 전에 타이틀·순위표로 나가면 준비 기록은 무효로 닫는다. 뒤로 가기 창이 떠 있는 동안은 경기 기록을 만들지 않는다.

## 스테이지·컬러 고르기

이 게임엔 스테이지·컬러 고르기가 없다(캐릭터 고르기에서 B·옵션은 아무 일도 안 함, 실측). 그래서 게임에 원래 있던 칸과 버튼에 얹었다.

| 무엇 | 어떻게 |
|---|---|
| 스테이지 | 1인 대전 배경은 상대가 아니라 **몇 번째 판(0x5827)** 을 따른다. 판이 뜨기 전부터 매 프레임 0~7 을 쓰면 그 배경으로 뜬다(CPU 단계·배율은 그대로). 8개: 후지산 마을 · 숲속 호숫가 · 산 위 신사 · 화염 사원 · 폐허 사원 · 불꽃 동굴 · 마계 제단 · 수정 신전. 상대마다 기본 스테이지가 있다(`League.HOME_STAGE`). 무작위는 확정 순간에 뽑는다 |
| 컬러 | 캐릭터·검질마다 기본 팔레트와, 미러전에서 P2 가 쓰는 공식 «2P색» 팔레트가 있다(14 × 2 실측 표 `PAL1`). 컬러 3·4 는 기본 색에서 만든다(가장 밝은 색은 두고 나머지 둘 색상 돌림). P1 몸 팔레트(스프라이트 팔레트 0)의 **세 색이 모두 기본 색일 때만** 고른 색으로 바꿔서, 맞을 때 번쩍임처럼 게임이 잠깐 쓴 팔레트는 그대로 둔다. 미러전에서 내가 2P색이면 P2 를 기본 색으로. 첫 라운드부터 라운드 사이 연출·결판 뒤 연출까지 |
| 깜빡임 없게 | 게임은 몸 팔레트를 롬에서 자주 다시 쓴다(대전 중 1초에 한 번꼴 — 3000프레임에 88번, 램에 사본 없음). 프레임 뒤에 고쳐 쓰기만 하면 그때마다 원래 색이 1~3 프레임(런어헤드 포함) 보인다. 그래서 코어에 **`retro_ngp_palremap`** 을 넣었다(ss2-sp-core 1249a9e·0966bed): 게임이 한 팔레트의 색 1~3 을 모두 «기본 색»으로 써 놓는 순간 코어가 셋 다 고른 색으로 바꿔 넣는다 — 런어헤드·프레임 생성 프레임까지 같다. 리그는 화면마다 표를 정한다(경기: P1 · 미러전 P2, 허브 내 캐릭터·유파 고르기: 커서 캐릭터의 두 검질). 원래 색 프레임 88 → 0 |
| 오른쪽 세로 이름 칸 | 원래 왼쪽 칸과 같은 커서 캐릭터 이름이 나오는 칸(둘째 판 3~11줄 × 17·18칸, 전용 타일 0x1E8~). 이 칸만 우리 글자로 바꾼다: 상대 선택 = 스테이지 이름, 내 캐릭터·유파 선택 = 컬러 이름. 글자는 빈 타일 0x130~0x141(모든 롬·고르기 화면에서 안 쓰임)에 갈무리11 12px(앱 글꼴과 같음, OFL)로, 원래 칸과 같은 칠 번호로 그린다. 게임이 칸을 다시 쓰면 새 값을 보관하고 다시 바꾼다. 왼쪽 칸(캐릭터 이름)은 그대로 |
| 미리보기 그림 | 캐릭터·유파 선택 가운데 그림도 스프라이트 팔레트 0 이다. 그 색이 커서 캐릭터의 컬러 0~3 중 하나면 고른 컬러로 바꿔 쓴다(커서를 옮기면 다시 맞춤) |
| B = 2P색으로 결정 | 내 캐릭터 고르기에서 B 를 받으면 컬러를 2P색으로 하고 A 를 대신 눌러 준다. 누른 B 는 뗄 때까지 게임에 안 줘서 유파 선택에서 «뒤로»로 새지 않는다 |
| 기록 | 고른 스테이지·컬러는 다음에도 그대로(`league.json` 의 설정), 경기 기록에 스테이지·컬러가 남고 결과 카드·리그 화면 상세에 보인다 |

화면 아래 띠는 버튼 안내만 남겼다(상대 선택 «A 도전 · B 스테이지», 내 캐릭터 «A 결정 · B 2P색으로 결정 · 옵션 컬러»). 스테이지·컬러 이름은 게임 화면 안에 있다.

### 안드로이드에서 찾아 고친 옛 버그

- **안드로이드 8~10 에서 아무것도 못 씀**: 앱이 읽기 권한만 받아 `/sdcard/PocketCore` 에 세이브·리그 기록·랭크전 롬 사본을 못 썼다
  (리그는 상대를 고르는 순간 «경기를 만들지 못했어요»). 쓰기 권한(maxSdk 29)·`requestLegacyExternalStorage` 를 더하고 8~10 에서 쓰기 권한을 확인·요청한다. 11+ 는 그대로(전체 파일 접근).
- **이미 한글패치가 든 롬을 랭크전 사본에 한 번 더 패치**: 한글패치 v1.01 롬을 넣고 한국어로 켜면 사본이 이중 패치돼 «판정 주소를 확인하지 않은 롬»으로 막혔다
  (쓰기가 안 되던 동안엔 사본을 못 만들어 원본으로 떨어져 드러나지 않았다). 원본이 실측한 한글패치 판(md5 표)이면 그대로 쓴다.
- **(이번 코드) 결과 카드 «계속» 뒤 앱이 죽음**: 카드를 닫으면 경기 id 를 먼저 비우는데, 리셋이 GL 스레드에 닿기 전 띠가 «경기» 상태로
  `League.matchById(null)` 을 불러 NullPointerException. 첫 판 «계속»에서 실제로 죽었고, 고친 뒤 둘째 판 «재대결 → 그만두기(무효) → 계속»은 끝까지 갔다.

## 남은 제약

- 게임 속 리그도 경기는 «1인 대전 첫 경기»다(2단계와 같음). 이긴 뒤 1인 대전의 다음 경기로 넘어가기 전에 결과 카드가 뜨고 리셋한다.
- 상대 정보(닉네임·순위·전적)는 게임 화면 안이 아니라 게임 그림 바로 아래 띠에 보인다. 게임 화면 안은 왼쪽 이름 칸 = 캐릭터 이름(그대로), 오른쪽 이름 칸 = 스테이지·컬러 이름. 가로 화면에선 띠가 게임 그림 위쪽 가장자리에 얇게 겹친다.
- 세로 칸 글자는 한글이라 순정 롬(일본어 굵은 글꼴)에선 글꼴 느낌이 조금 다르다. 컬러 3·4 는 게임에 없는 색이라 만든 색이다.
- 컬러를 깜빡임 없이 보이려면 코어에 `retro_ngp_palremap` 이 있어야 한다(ss2-sp-core 1249a9e 부터). 이 패치를 다른 머리에 붙이고 그쪽 동봉 코어(ci-core)를 그대로 쓰면 리그는 돌지만 컬러가 가끔 깜빡인다.
- 순정 롬 메뉴는 «LEAGUE»(영문 글자 재사용), 머리말은 한글 «상대 선택»이다(순정 롬 글꼴엔 한글이 없어 그려 넣음).
- 에뮬레이터 실기는 느린 소프트웨어 CPU 라 «게임이 끝까지 되는지»를 본 것이고, 조작감·속도는 실제 폰에서 봐야 한다.
  (기계가 바쁘면 에뮬레이터의 SystemUI 가 «응답 없음» 창을 띄워 누름을 가로챈다 — 시험할 땐 `adb shell pm disable com.android.systemui` 로 끄고 재부팅. 화면 패드 옵션 버튼은 (540, 2120).)
  이긴 판(점수 +)·화면 돌리기·앱이 내려갔다 돌아오기(체크포인트 이어 하기)는 에뮬레이터로 안 해 봤다 — 정산·이어 하기는 2단계 시험 그대로.
- 가운데 칸은 게임에선 «쿠로코»(무작위)로 보이지만 리그에선 유가 자리다(띠에 «가운데 칸 = 숨은 상대»).
- **120Hz 폰(코어 2배 출력)에선 이 판의 허브가 합성 호출에도 돌아 프레임 셈이 두 배였다**(대신 누르는 A·리셋 뒤 길 찾기가 빨라짐 — 에뮬레이터는 60Hz 라 안 드러남).
  연습 대전 1단계 판(`release/legacito-practice-s1/`, 같은 패키지 · 리그 포함)에서 고쳐짐 — `handoff/ss2_practice/1단계_연습대전.md`.
