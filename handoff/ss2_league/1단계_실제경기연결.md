# SS2 가상 리그 1단계 — 실제 경기 연결 (Legacito)

기획서 「NGP 사무라이 쇼다운 2 가상 리그 v1」 5장 1단계: **상대 1명, 원작 직접 조작, 최종 결과 감지와 기록.**
가상 상대(칼끝노인 · 우쿄 · 수라 · 난도 보통)를 골라 실제 경기를 하고, 경기 전체 승패가 자동으로 기록되며, 앱을 다시 열어도 기록이 남는 한 사이클을 Legacito 에 넣었다.
상대는 게임의 CPU 다. 화면에 그렇게 적었고, 온라인 사람처럼 보이게 하지 않는다.

> 진행 상태: 소스·검수 도구는 올라가 있고, 코드 리뷰 반영 뒤 APK(`release/legacito-league-s1/`)와 소스 패치를 올린다.

## 설치와 실행

1. `Legacito-league-s1.apk` 를 설치한다. 패키지가 `com.dudu.legacito.league`(표시 이름 「Legacito 리그」)라 **정식 Legacito 와 나란히 깔린다.**
   공개 시험 키(`CN=PocketCore fgtest`)로 서명했다 — 정식 Legacito 키는 유저만 갖고 있어서다. 정식판에 넣을 때는 같은 소스를 `release-unsigned` 로 굽고 유저 키로 서명한다(`tools/SIGNING.md`).
2. 처음 켜면 Legacito 와 같이 「모든 파일 접근」을 허용한다. 롬 폴더·한글패치는 Legacito 와 같은 저장소를 쓴다.
3. 런처에서 사무쇼2 카드 → 실행 창 아래 **「가상 리그 (시험) — CPU 상대 랭크전 ›」** → 랭킹 화면.
4. 칼끝노인 → **도전**. 게임이 켜지면 1인 대전 캐릭터 고르기까지 앱이 대신 들어간다. 내 캐릭터·검질·카드를 고르면 첫 상대로 칼끝노인(우쿄)이 나온다.
5. 경기 전체 결판이 나면 게임이 멈추고 리그 화면에 결과 창이 뜬다: 최종 승패와 승수, 점수·순위 변화, 상대전적, 연승. **재대결** 또는 **랭킹으로**.

이 밖의 롬·코어면 경기를 시작하자마자 «자동 정산 중지 — 이유»를 띄우고 그 경기를 **보류**로 남긴다(점수 안 움직임).
여섯 판 모두에서 아래 «검수 결과»의 경기 흐름을 실제 코어로 돌렸다.

## 들어간 것

**실행부(native, `league.c`)** — 앱 프레임 루프에서 진짜 프레임마다(retro_run 뒤, 코어 잠금 안) 한 번:
- 대진: 결판 전까지 상대 `0x57DF`·유파 `0x57E0` 를 쓴다. CPU 카드 `0x57E6/7 = 0xFF`(카드 없음).
- 규칙: 옵션 `0x636A` 난도(상대 설정) · `0x636B` 2선승 · `0x636C` 60초 — 롬 세이브 기본값(포인트 1 일 수 있다)에 기대지 않는다.
- 올카드: 캐릭터·유파 고르기 화면(MODE 240 · SCR 2/4)에서 카드 소유 120칸을 8로. 게임이 모드를 고를 때 세이브에서 다시 읽어 덮으므로 그 뒤에 쓴다.
- 메뉴 자동 진입: 새로 켠 판이면 무장 뒤 20·60 프레임에 A(사이는 뗀다) → 1인 대전 캐릭터 고르기. 그 화면이 30프레임 이어지면 손을 떼고, 400프레임 안에 못 닿아도 손을 뗀다. 그동안만 사용자 입력을 막는다.
- 경기 시작: `(0x40A7==241 && 0x411A==1 && 0x5824==0)` 이 서는 첫 프레임 + 승수 0:0 + 이어하기 횟수 `0x5804==0`. 그때 P2 블록을 남긴다.
- 최종 결과: `0x5824` bit7 이 0 인 걸 본 뒤 1 로 서는 **첫 프레임 한 번**. 승자 = 0x40 P1 / 0x20 P2 / 둘 다 없으면 무승부, 승수 `0x5821/0x5822`, P1·P2 블록, 사용자 카드.
- 런어헤드·프레임 생성의 숨은 프레임은 코어 안에서 되돌려지므로 여기 오지 않는다(런어헤드 2·프레임 생성 켬에서 끔과 같은 프레임·같은 값 확인).

**앱(Java)**
- `League` — 기록 저장소와 정산. `루트/league/league.json` 원자 저장(임시 파일 → fsync → 이름 바꾸기, 같은 내용을 `.bak` 에 한 벌 더).
  - 시작 전에 경기 id(UUID)·상대·규칙을 저장하고 시작한다. 저장 실패면 시작하지 않는다.
  - 정산 = 결과 + 점수 변경 + 상태(정산 완료)를 **한 번의 저장**으로. 같은 경기 id 는 다시 정산하지 않는다. 저장이 실패하면 메모리를 되돌리고 1초 뒤 다시 한다(결과는 코어 쪽에 그대로 있다).
  - 대진 불일치(결판 때 P2 블록 ≠ 표시한 상대)면 점수에 넣지 않고 **보류**.
  - 점수: 시작 시점 두 점수로 구간 고정, 기획서 3장 표(+18/−6, ±12, +6/−18), 상대에는 내 변화량의 반대. 무승부는 점수 유지·무승부 전적만. 기권은 패배와 같은 변화.
  - 경기 상태: ready 준비 · playing 진행 중 · settled 정산 완료 · resume 복귀 대기 · forfeit 기권 · hold 오류 보류.
- `LeagueActivity` — 랭킹(점수 내림차순, 동점은 기존 순서·나 먼저), 상대 상세(캐릭터·검질·난도·나와의 전적·최근 경기·규칙), 진행 중 경기(재개/기권), 결과 창.
- `EmuActivity` 랭크전 모드
  - 랭크전 전용 세이브 폴더(`루트/league/saves/`) — 올카드·옵션이 게임오버 때 `.flash` 에 써져도 원작 세이브는 그대로.
  - 원작 오토세이브를 읽지도 쓰지도 않는다. 불러오기·되돌리기·리셋·실행 옵션 다시 굽기를 막는다.
  - 체크포인트: 앱이 내려가는 **그 순간**만 저장, 다시 올라오면 지운다. 다음에 재개하면 한 번 쓰고 지운다 — 되감기로 못 쓴다.
  - 뒤로 가기: 계속하기 / 나중에 이어하기(체크포인트) / 기권.
  - 게임 화면 밖(위쪽 메뉴 알약 줄 왼쪽)에 «랭크전 · 칼끝노인 (우쿄 · 수라)» — 게임 안 이름(우쿄)과 닉네임(칼끝노인)을 가른다.
- `Patcher.resolveLeague` — 랭크전 고정 사본. `LaunchSheet`·`MainActivity` — 사무쇼2 실행 창에 리그 입구.

## 검수 결과

안드로이드 기기·에뮬레이터는 이 작업 환경에 없다(KVM 없음). 대신 **앱과 같은 C 코드(league.c)를 실제 코어(같은 소스의 리눅스 빌드) 옆에서** 돌리고, 정산 코드는 JVM 에서 돌렸다.

| 검수 상황(기획서 «필수 검수 항목») | 결과 |
|---|---|
| 승리와 패배 — 중간 라운드 제외, 경기 전체만 1회 | 2:0 승 · 0:2 패 · 더블 KO 무승부 라운드 낀 2:1 승 · 카드 장착 2:0 · 체크포인트 재개 2:1 — 모두 결판 프레임에 1회, 3000 프레임 더 돌려도 다시 안 잡힘 |
| 대진과 규칙 — 표시한 상대·검질 = 실제 화면 | P2 블록 0xB0(우쿄 수라)·0x48(나코루루 나찰), 화면으로도 확인. 0단계에서 15캐릭 × 2검질 30/30 |
| 직접 조작 | 사람은 늘 P1 블록(화면 좌우가 바뀌어도). 메뉴 자동 진입은 캐릭터 고르기까지만, 그 뒤 입력은 사용자 것 |
| 중복과 저장 실패 | 같은 결과 반복·재시작 뒤 재전달 → 점수 1번 · 저장 실패 → 되돌림, 재시도에서 1번 · 기권 연타 → 1번 |
| 종료와 재접속 | 시작 전 영속(재시작 뒤 ready) · 진행 중 종료 → 재개(체크포인트) 또는 기권 · 정산 직후 재시작 → 같은 기록 · 기록 파일이 깨지면 .bak 에서 최신 그대로 |
| 세이브와 되감기 | 랭크전은 불러오기·되돌리기·리셋 막음, 체크포인트 1회용·내려간 순간만, 자유 플레이 세이브·오토세이브는 안 건드림 |
| 버전 불일치 | 허용 md5·동봉 코어가 아니면 정산 중지 + 이유 표시 + 보류 |
| 무승부 | 경기 무승부(0x90, 3:3) → 점수 유지, 무승부 전적만 |
| 실행 버전 | 위 여섯 사본 모두 같은 흐름 통과(메뉴 자동 진입 → 올카드 카드 화면 → 경기 시작 감지 → 결판) |

JVM 시험(`LeagueTest.java`) 15항목 모두 통과. 호스트 하네스 시나리오(`t_full.py` w/l/d · `t_resume.py` a→b · `t_nav.py` card/nocard)를 세 롬(+ss2_h1 두 판)에서 모두 통과.

## 남은 제약

- **실기 미확인.** 빌드·서명·심볼·클래스까지 확인했지만 폰에서 돌려 보지는 못했다. 화면 배치(이름표 자리)·패드 입력은 실기에서 볼 것.
- 1단계라 가상 상대는 1명. 2단계(12명, 순위표·재대결 확장)는 `League.fresh()` 명단과 `rankOf` 만 늘리면 된다.
- 결판 뒤 게임은 원래 다음 장 이야기로 가지만 앱이 그 자리에서 멈추고 리그 화면으로 돌아간다.
- VS PLAY(통신)는 코어의 링크 케이블 처리가 접속 확인에서 멈춰(2026-08 미완성 그대로) 확인하지 못했다. 리그는 CPU 전이라 무관.
- Legacito 의 조작 패치 `ss2_allcards.ips` 는 세이브의 카드 개수를 255(게임 범위 0~8 밖)로 만들어 카드 모음집 숫자가 깨진다(0단계 재조사에서 발견). 랭크전은 이 패치를 안 쓰고 램으로 올카드를 준다.
