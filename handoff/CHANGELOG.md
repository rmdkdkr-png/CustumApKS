## SS2-1.0.2 (2026-08-26)

간다라 인식 버그 수정판. 기능 추가 없음.

- **간다라를 못 알아보던 문제**: 판별이 보스 플래그를 요구했는데, 같은 간다라전이
  플래그 1 로도 0 으로도 온다. 제보 세이브 14장이 전부 플래그 0 이라 하나도 안 걸렸다.
  **개체 번호(19) + 스테이지(7) 두 값만으로** 가르도록 고쳤다 —
  실측 23장(스토리 주행 9 + 제보 14) 대조 결과 스테이지 7 에는 개체 19 밖에 오지 않고
  개체 19 도 스테이지 7 에만 온다
- **아수라 보스전 오인 제거**: 「개체 8 + 보스기 = 간다라」는 오독이었다.
  그 판은 스테이지 6 의 직전 장 보스전이고(같은 자리에 13+보스기=시키도 온다),
  간다라는 그 다음 장 스테이지 7 에 나온다. 로스터대로 부르게 돌려놓았다
- **다른 게임에서 SS2 층이 완전히 꺼진다**: 사쇼!2 가 아닌 롬을 띄우면 좌우에
  빈 기둥이 서고 화면이 288×184 로 잡히던 문제. 엔진은 검증합이 안 맞으면 그림만
  생략했지만 화면 합성과 SET_GEOMETRY 는 무조건 돌고 있었다. 롬 헤더로 판별해
  기둥·해설띠·오버레이·원버튼을 통째로 끄고 원본 해상도로 내보낸다 (코어 전용)
- 코어 옵션 설명의 해설띠 크기 오기 정정 (30px → 32px)
- versionName 1.5.85-SS2-1.0.2 / versionCode 16010592

## SS2-1.0.1 (2026-08-25)

- **빠른 설정 = 일시정지**: 설정창이 열려 있는 동안 게임·소리가 완전히 멈춘다
- **일러 변형 4종 로테이션**: 캐릭터가 기둥에 설 때(콜) 4장 중 랜덤 1장을 정해 유지
  — 60장 전 변형에 「두 눈이 보이게」 얼굴 초점 수동 확정
- **전황 연출**: 빈사 시 기둥이 붉게 물들고, KO 순간 진 쪽이 흑백으로 바뀐다
- **기둥 배경 구간(슬라이스) 기능 폐지** — 매치 전 기둥 장식 아트는 지명 대기
- **SS2 전용 잠금**: 다른 롬은 열리지 않는다(헤더 판별) — 범용 에뮬로 쓰여
  원작자(EmuEx) 유료 앱의 이익을 침해하지 않게
- 빠른 설정에 **원버튼 필살기** 토글 추가
- **앱 이름 「NGPcustumSP」** (원작 상표 NGP.emu·NEO.emu 와 구분) +
  시스템 설정에 **버전 정보** 란
- **SP 기술 배치 오버레이**: 빠른 설정 마지막 줄에서 진입 — 캐릭터·유파 고르고
  7슬롯(기본/→앞/←뒤/↓아래/↘/↙/공중)마다 **A로 기술 목록에서 선택**,
  커맨드는 전부 화살표 표기(↓↘→+A), 공중기는 (공중) 표기, 기본 배치로 되돌리기,
  B는 한 겹씩 복귀(고르기→배치→빠른 설정→닫기)
- **공중기 지상 발동(타이거니)**: 공중 전용기를 지상 슬롯에 배치하면
  커맨드 뒤 ↗+버튼을 자동으로 넣어 저공 발동 (유저 제보 2369 기계화, 실측 검증)
- **히트 충격**: 맞은 쪽 기둥 일러가 피해량 비례로 흔들리고 강타는 백섬광
- **매치포인트 장식 폐지**: 금테·집중선은 만들었다가 걷어냈다 — 기둥 장식은
  위아래 금줄 두 줄만 남기고, 전황은 흔들림·백섬광·틴트·흑백으로만 말한다
- **간다라 기둥 일러**: 전투 인트로 포효 실측 — 몸(스크롤면)+얼굴(스프라이트)
  이중층 합성(주소표+오버레이표), 간다라전에서 우측 기둥에 뜬다
- **해설 방향 정정**: 같은 기술 3연속은 「내 기술이 먹힌」 상황 — 15화자 대사를
  상대-피격 방향으로 재작성
- **나코루루 단일화**: 항상 상냥한(수라) 문안 — 레라·이중인격·나찰 말투 폐기
- versionName 1.5.85-SS2-1.0.1 / versionCode 16010591

### 코어(libretro) 판 — 앱과 같은 기능으로
- 기둥 아트·해설띠·심판·빠른 설정 오버레이·SP 기술 배치까지 **앱의 기능을 전부 이식**.
  오버레이는 아래+START 콤보로 열고, 열려 있는 동안 코어가 에뮬레이션을 멈춘다
- 해상도는 기둥·해설 상태에 따라 288×184 ↔ 160×152 로 바뀐다(SET_GEOMETRY)
- 코어 옵션 7종(`ngp_language`, `ngp_ss2sp`, `_comm`, `_comm_spk`, `_comm_duo`,
  `_comm_draw`, `_sides`) ↔ 오버레이 값 양방향 동기
- **해설띠 기본 위치를 위로** (앱 엔진 기본값도 함께) — 아래는 옵션으로 남는다
- 코어 전체 소스를 저장소에 편입(GPL 대응 소스 요건)
- 배포는 플랫폼별 개별 파일 6종: 안드로이드 5 ABI + 리눅스 x86_64
- **버전 스탬프 고정**: `git rev-parse` 를 호출 셸의 작업 디렉터리에서 돌리던 탓에
  안드로이드 빌드가 엉뚱한 저장소의 커밋을 찍었다 — `git -C` 로 코어 트리에 못박아
  6종이 항상 같은 커밋을 보고하게 했다 (실행 검수 보고 「커밋 불일치」 항목)

## SS2-1.0.0 (2026-08-25) — 첫 정리 릴리즈

### 해설 엔진
- 15인 캐릭터 해설 + 심판 쿠로코(안무·팻말·구호 한국어) + 한 줄 공유 창
- 전투 반응 ~750줄이 상대 이름을 부른다 · 거울전 가드 · 맹탕 변형 솎음
- 썰(세계관) 225칸 화자 목소리화, 위키체는 「~라더군」류 전달어미 자동 부착
- 상대 정체: 개체번호+보스 플래그 전수 실측표 (그림자·간다라·이벤트전 구분)
- 연승 장부: 타임오버·1라운드·리매치·잔존 카운터 전부 정산
- 강베기(시그니처) 명명, 밀린 대사 폐기, 심판 안무 중 캐릭터 침묵
- **장면 게이트(세이브 검수 93장 전수)**: 타이틀·컬렉션·카드·스토리 문구 침묵,
  선택 화면은 고른 적 있어야 캐릭터 썰, 시드는 램으로 랜덤화

### 화면
- 양옆 기둥: 카드 대형 일러(96×96, 15인 전원)를 **타일별 롬 주소표**로 재구성 —
  그림은 배포물에 없음, 실행 중 유저 롬에서 굽는다. 색인0=흰색(투명 보정)
- 세로샷: 일러 2배 확대로 기둥 세로 꽉 채움 + 하단 이름띠
- 기둥 배경: 스테이지 타일 정적 굽기, 자동/구간1~6/격자 선택(저장값 0..7)
- 지속 대화띠(화자 유지 시 흐림 유지), 심판 독립 온오프

### 조작·설정
- 빠른 설정 오버레이(게임 화면 위): 캐릭터 해설/해설자/심판/기둥 아트/배경/진동/장면 수집
  — **아래+옵션** 콤보 또는 Quick Settings 가상 버튼(키보드 V), B·옵션으로 닫기
- 해설자 교대 버튼(Commentator), A+B 단추(C), SP 원버튼 필살기 층(ss2sp)

### 도구·검증 (handoff)
- `harvest_art.py`: 상태파일 VRAM→롬 주소표 수확 (앱 gzip 상태 지원)
- `verify.sh` 기준표 54항 + 롬 혼입 검사 · test_flow 20종 · 글꼴 커버리지 상시 검사
- 장면 자동 수집(_scene* 상태·램·화면 덤프) — 검수 입력으로 사용

### 알려진 것 / 보류
- 컬렉션 「소00장」(200의 2 깨짐): 한글패치 자체 버그, 문자열이 코드 계산식이라 추적 보류
- 나코루루 목록 헤더 깨짐: 수정 코드는 엔진에 있으나(ss2comm_rom_fix) 자동 적용 해제 —
  유저가 롬을 직접 패치하기로 함
