## SS2-1.1.0 (2026-10-09) — 프레임 생성 (120Hz)

60fps 게임을 120Hz 화면(갤럭시 Z 폴드6)에 맞춰 **중간 프레임을 합성**한다. 픽셀을 섞지 않고
그래픽 칩(K2GE)의 스프라이트표·스크롤 레지스터를 두 프레임에서 캡처해 위치만 반 옮긴 자리에
같은 타일을 원본 렌더러와 같은 규칙으로 다시 그린다 — 픽셀아트가 번지지 않는다.

- **코어(libretro)**: 옵션 「프레임 생성 (120Hz)」자동/끔/켬 + 「방식」예측(기본, 추가 지연 0 —
  상태를 저장한 채 다음 프레임을 미리 돌려 현재↔다음 중간을 그리고 되돌림)/보간(+8ms).
  자동 = RetroArch 주사율 설정이 120Hz(짝수 배)일 때만 fps 120.5 선언. 런어헤드 감지 시 물러남.
  오디오는 실제 프레임 샘플을 반씩 두 호출에. 링크 케이블 중엔 예측 안 함.
  엔진 파일 `src/ss2fg.c/.h` (mednafen 비의존 순수 C) — 앱도 같은 파일.
- **앱(NGP.emu)**: 시스템 옵션 「프레임 생성 (120Hz)」(기본 켬). **프레임 타이밍 옵션 →
  화면 주사율 덮어쓰기 = 120Hz** 로 두면 vsync 두 번에 한 번 비는 슬롯에 중간 프레임을 올린다
  (EmuFramework 의 빈 슬롯 훅 `EmuSystem::interFrame` 추가). 예측 방식만.
- 합성하지 않는 경우(그 순간만 60Hz 와 같음): 표시 도중 스프라이트표/타일맵을 고쳐 쓴 프레임,
  흑백 모드, 24px 넘는 스프라이트 점프·32px 넘는 스크롤 점프(순간이동·장면 전환), 타일이 바뀐
  조각(단, 체인 그룹의 다른 조각이 한 방향이면 같이 이동).
- 검증(롬 없이): 합성 렌더러 1,546건(원본 K2GE 렌더러와 동치·중점·체인·스크롤 랩·래스터·더티),
  배관 55건(2배 fps 전환·오디오 분배·예측 후 400 프레임 상태 바이트 동일·런어헤드 가드).
  **실제 롬 화면에서의 품질(슬롯 안정성·폴백 빈도)은 아직 실측 전.**
- 윈도우 DLL 다시 빌드됨(링크 파이프 코드 윈도우 가드).
- 「DLSS 같은 거」: DLSS/FSR2·3/SGSR2 는 엔진 통합(모션벡터·뎁스 필요)이라 불가, 업스케일(FSR1·
  xBRZ 등)은 RetroArch 셰이더로 이미 있고 움직임엔 무관, 픽셀 기반 프레임 생성(LSFG-Android)은
  50~80ms 지연+픽셀아트 번짐, 폴드6엔 MEMC 칩 없음 — 코어 `docs/프레임생성.md` 참고.
- 코어 옵션 설명·RetroArch 안드로이드 120Hz 설정 절차(Threaded Video 끄기, Vertical Refresh
  Rate 120 또는 nightly 의 Screen Resolution 120Hz 모드, Automatic Refresh Rate Switch 끄기,
  런어헤드 끄기, 삼성 게임 부스터 60Hz 고정 풀기): 코어 `docs/프레임생성.md`.

- **앱 이름 「NGPcustumSP」** (원작 상표 NGP.emu·NEO.emu 와 구분) +
  시스템 설정에 **버전 정보** 란
- **SP 기술 배치 오버레이**: 빠른 설정 마지막 줄에서 진입 — 캐릭터·유파 고르고
  7슬롯(기본/→앞/←뒤/↓아래/↘/↙/공중)마다 **A로 기술 목록에서 선택**,
  커맨드는 전부 화살표 표기(↓↘→+A), 공중기는 (공중) 표기, 기본 배치로 되돌리기,
  B는 한 겹씩 복귀(고르기→배치→빠른 설정→닫기)
- **공중기 지상 발동(타이거니)**: 공중 전용기를 지상 슬롯에 배치하면
  커맨드 뒤 ↗+버튼을 자동으로 넣어 저공 발동 (유저 제보 2369 기계화, 실측 검증)
- **히트 충격**: 맞은 쪽 기둥 일러가 피해량 비례로 흔들리고 강타는 백섬광
- **매치포인트 장식 폐지**: 금테·집중선은 만들었다가 걷어냈다 — 기둥 장식은
  위아래 금줄 두 줄만 남기고, 전황은 흔들림·백섬광·틴트·흑백으로만 말한다
- **간다라 기둥 일러**: 전투 인트로 포효 실측 — 몸(스크롤면)+얼굴(스프라이트)
  이중층 합성(주소표+오버레이표), 간다라전에서 우측 기둥에 뜬다
- **해설 방향 정정**: 같은 기술 3연속은 「내 기술이 먹힌」 상황 — 15화자 대사를
  상대-피격 방향으로 재작성
- **나코루루 단일화**: 항상 상냥한(수라) 문안 — 레라·이중인격·나찰 말투 폐기

### 코어(libretro) 판 — 앱과 같은 기능으로
- 기둥 아트·해설띠·심판·빠른 설정 오버레이·SP 기술 배치까지 **앱의 기능을 전부 이식**.
  오버레이는 아래+START 콤보로 열고, 열려 있는 동안 코어가 에뮬레이션을 멈춘다
- 해상도는 기둥·해설 상태에 따라 288×184 ↔ 160×152 로 바뀐다(SET_GEOMETRY)
- 코어 옵션 7종(`ngp_language`, `ngp_ss2sp`, `_comm`, `_comm_spk`, `_comm_duo`,
  `_comm_draw`, `_sides`) ↔ 오버레이 값 양방향 동기
- **해설띠 기본 위치를 위로** (앱 엔진 기본값도 함께) — 아래는 옵션으로 남는다
- 코어 전체 소스를 저장소에 편입(GPL 대응 소스 요건)
- 배포는 플랫폼별 개별 파일 6종: 안드로이드 5 ABI + 리눅스 x86_64
- **버전 스탬프 고정**: `git rev-parse` 를 호출 셸의 작업 디렉터리에서 돌리던 탓에
  안드로이드 빌드가 엉뚱한 저장소의 커밋을 찍었다 — `git -C` 로 코어 트리에 못박아
  6종이 항상 같은 커밋을 보고하게 했다 (실행 검수 보고 「커밋 불일치」 항목)
