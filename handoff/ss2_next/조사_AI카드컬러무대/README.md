## 1. AI가 생각보다 세다 / 카드 붙여서 그런가?

### 결론
느낌은 맞습니다. 랭크 초반 상대는 스토리 보통 1장보다 셉니다.
하지만 **카드 때문은 아닙니다.**

### 카드가 원인이 아닌 이유 (실측)
- 랭크 상대가 끼고 나오는 카드 두 장은 지금 **거의 화면 장식**입니다.
- 공격력상승·방어력상승 카드: 앱이 매 프레임 상대 세기(배율)를 직접 써 넣습니다. 그래서 카드 효과가 바로 지워집니다.
  - 카드 있음/없음을 비교하면 타격 하나하나까지 똑같았습니다.
- 센 상대(대략 MMR 1250 이상)가 끼는 추가필살기 카드: 기술만 하나 열어 줍니다.
  - 평균적으로는 오히려 0.92~0.99배로 살짝 약해졌습니다.
  - 나코루루는 그 기술을 쓰다가 오히려 크게 약해졌습니다.
  - 우쿄·샬롯은 그 기술을 아예 안 썼습니다.
- 참고로 원작 스토리는 CPU가 카드를 거의 안 낍니다. 마지막 유가 두 판만 낍니다.

### 진짜 원인: "단계 바닥" (실측)
- 원작 CPU는 플레이어에게 밀리면 스스로 단계를 낮춥니다. 일부러 봐주는 겁니다.
- 랭크는 "너무 물러지지 않게" 바닥을 두었습니다. 시작 단계에서 2 아래로는 안 내려갑니다.
- 결과 (같은 배율, 바닥만 다름. 단순 연타 봇 기준):
  - 스토리 보통 1장: 봇 승률 0.78
  - 랭크 MMR 1000 상대: 봇 승률 0.50
  - Elo로 치면 약 220점 차이입니다.
- 랭크 세기 곡선은 바닥이 생기기 **전에** 맞춰 놓은 것입니다. 그래서 지금은 곡선 전체가 MMR 200쯤 세게 나옵니다. (추정)
- 공격형 성향 상대는 단계가 +2라서 바닥도 +2입니다. 이쪽도 체감에 보탰을 수 있습니다. (추정, 측정 안 함)
- 하나 더: **내 카드는 랭크에서 제대로 먹힙니다.** 지워지는 건 상대 카드뿐입니다.

### 제안
1. **단계 바닥부터 고치기** (제일 먼저, 0.5~1일)
   - MMR 1000 아래는 바닥 0, 위로 갈수록 천천히 올립니다.
   - 그다음 봇 사다리로 세기 곡선을 다시 맞춥니다.
   - 바닥 0이면 MMR 1000 상대가 스토리 보통 1장과 같아집니다 (봇 승률 0.78, 실측).
   - 바닥 1은 아직 안 재 봤습니다. 다시 맞출 때 같이 잽니다.
2. **티어별 진짜 카드** (3~4일)
   - 원작 무한대전이 CPU에게 카드를 주는 방식을 따릅니다. 실측해 보니 원작은 두 장을 주는 일이 없었습니다.

   | 티어 | 상대 카드 |
   |---|---|
   | 수련생 · 낭인 · 무사 | 없음 |
   | 검객 | 공격력상승 또는 방어력상승 1장 (성향 따라) |
   | 검호 | 위 1장 또는 ★★★ 카드 1장 (반반) |
   | 달인 | ★★★ 카드 1장 |
   | 검성 · 무쌍 | ★★★ + 공/방 1장 (리그 전용 "두 장") |

   - 카드 효과는 진짜로 먹게 합니다. 대신 카드 몫만큼 기본 세기를 낮춰서 총 세기는 티어에 맞춥니다.
   - 카드 한 장이 얼마나 센지는 아직 오차가 큽니다 (±150 MMR). 출시 전에 사다리를 한 번 더 돌려야 합니다.
   - ★★★ 기술은 캐릭터마다 득실이 다릅니다. 캐릭터별로 한 번씩 재 봐야 합니다.
3. **상대 카드 보여주기** (위 작업에 포함)
   - 「상대 발견!」과 결과 카드에 한 줄 넣습니다. 예: «능력 카드 · 공격력상승 ★★»
   - 카드가 "왜 센지"를 알려 주는 티어 배지가 됩니다.
- 2번을 미룬다면: 낮은 티어 상대의 장식 카드만이라도 먼저 빼는 게 좋습니다 (0.5일). 효과 없는 카드가 보이면 오해만 생깁니다.

## 2. 카드 관련 추가 기믹

### 결론
**됩니다.** 다만 게임 안에 "새 카드 종류"를 등록하는 방식은 아닙니다.

### 이유
- 원작 카드는 딱 4종이고, 표가 아니라 코드에 박혀 있습니다. (실측)
  - 공격력상승: 주는 피해 +20%p, 받는 피해 +4.7%p
  - 방어력상승: 받는 피해 −20%p, 주는 피해 −4.7%p
  - 추가필살기 1·2: 해당 기술을 열어 줌
- ★ 등급과 카드 주인 캐릭터는 전투에 영향이 없습니다. (실측)
- 그래서 새 효과는 두 길로 넣습니다.
  - **앱이 매 프레임 게임 메모리를 보고 효과를 넣는 방식.** 롬은 그대로입니다.
  - **메모리에 올라간 롬 몇 바이트를 고치는 방식.** 지금 KO 보호 패치와 같은 방법입니다.

### 아이디어 목록

| 기믹 | 효과 | 확인 | 난이도 |
|---|---|---|---|
| 흡혈 | 준 피해의 절반만큼 회복 | 실측 | 쉬움 |
| 재생 | 0.5초마다 체력 +1 | 실측 | 쉬움 |
| 분노가속 | 분노 게이지가 빨리 참 | 실측 | 쉬움 |
| 배수진 | 체력이 적으면 공격력 +25% | 원리 실측 | 쉬움 |
| 시간 벌기 | 맞힐 때마다 시간 +3초 | 추정 | 쉬움 |
| 선제일격 | 첫 타격 피해 ×2 | 실측 | 보통 |
| 반격 보너스 | 카운터 히트 +50% | 감지 실측 | 보통 |
| 철벽 | 막을 때 깎이는 피해 되돌림 | 추정 | 보통 |
| 가드 크러시 | 막아도 깎이는 피해 ×3 | 추정 | 보통 |
| 카드 숫자 조정 | 예: 공격력상승 두 배 | 실측 | 보통 |
| ★★★ 카드에 작은 능력치 | 기술 + 공격력 조금 | 실측 | 보통 |
| 비기 해금 | 카드 없이 추가필살기 전부 사용 | 한 기술로 실측 | 보통 |
| 속도 증가 | 움직임 빨라짐 | 안전한 방법 못 찾음 | 비추천 |
| 게임 카드 화면 글자 바꾸기 | 공격력상승 자리에 새 이름 | 위치만 확인 | 어려움 (앱 화면에 표시하는 게 쌈) |

### 주의할 점
- 랭크 공정성: 기믹 판은 일반 랭크와 따로 두는 게 좋습니다. 이벤트 리그나 별도 기록으로요.
- KO 관련 효과(선제일격, 반격)는 체력을 직접 깎지 않습니다. 게임 피해 계산을 거치게 해야 합니다. 이 게임에는 "체력 0인데 KO 안 됨" 멈춤 버그가 있었습니다.
- 저장/불러오기 때 효과가 두 번 들어가지 않게 치트와 같은 처리를 합니다.

### 품
- 기본 기믹 6개 엔진: 3~5일
- 카드 숫자 조정 / 비기 해금: 1~2일

## 3. 상대마다 커스텀 컬러

### 결론
**됩니다.** 시제품을 만들어서 확인했습니다. (실측)
- 9가지 대전에서 상대 원래 색이 **한 프레임도** 안 새어 나왔습니다.
  - 거울전, 같은 캐릭 다른 검질, 유가 포함
- 내 색도 동시에 그대로 유지됐습니다.
- 인트로 · 싸움 · 라운드 사이 · KO · 승리 대사 · 저장/불러오기까지 다 봤습니다.

### 방법
- 상대 프로필마다 **고정 대표 색**을 줍니다.
  - 지금 있는 16가지 색 중 하나
  - 10~20%는 그 사람만의 색을 새로 만들어 줌
  - 기존 12 라이벌은 손으로 고른 대표 색
- 캐릭터가 정해지듯 색도 첫 만남 때 정해지고 계속 갑니다.
- 기존 상대들의 이름·캐릭터는 바뀌지 않게 따로 계산합니다.
- 같은 캐릭터 거울전에서 내 색과 겹치면 자동으로 두 번째 색으로 바꿉니다.
- 표시: VS 띠에 색 이름, 프로필·결과 카드에 색 견본 + 이름.
- 새 색을 손으로 만드는 것도 됩니다. 4096색 중 3색 조합입니다.

### 한계
- 딸린 동물(콘루 등)과 MAX 컷인 얼굴은 원래 색입니다. 게임 자체 규칙입니다.
- 리그를 나갈 때 색 설정을 꼭 지워야 합니다. 아니면 같은 캐릭터가 다른 모드에서도 그 색으로 나옵니다.

### 품
1.5~2일

## 4. 스테이지 추가 — 기술적으로 불가?

### 결론
**불가능하지 않습니다.** 엔진 쪽은 됩니다. (실측)
- 새 무대 데이터를 끼워 넣고 한 판을 끝까지 돌렸습니다.
- 인트로, 3라운드, KO, 승리 대사까지 문제없었습니다.
- 무대 개수 제한도 사실상 없습니다.

### 진짜 벽은 그림
- 새 무대 하나에 필요한 것:
  - 320×128 크기 그림 (승리 포즈 때 화면이 위로 움직여서 전부 그려야 함)
  - 8×8 타일 250개 이하
  - 3색 팔레트 16개 + 배경색 1개
  - 네오지오 포켓 도트 느낌
- 기존 무대 조각을 섞어 쓰는 건 사실상 안 됩니다. 무대마다 250칸 중 243~250칸을 이미 씁니다.
- 원작 무대도 정지 그림입니다. 물·불 움직임이 없습니다. 새 무대도 마찬가지입니다.
- 롬 크기를 그냥 키우면 타이틀·세이브가 깨집니다. 롬 바깥 별도 공간에 넣는 방식은 확인했습니다.

### 품
- 엔진 + 그림 변환 도구: 3~5일 (한 번만)
- 그림: 무대당 3~7일 (숙련 도트 작가 기준)
- 확인: 무대당 1일

### 숨은 보너스: 새 그림 없이 3개 추가
- 롬에 SNK가 그린 **밤 무대 3개**가 있습니다. 2라운드부터만 나옵니다.
  - 후지산 마을: 달과 별
  - 숲속 호숫가: 밤
  - 산 위 신사: 보랏빛 저녁
- 이걸 1라운드부터 고르게 할 수 있습니다. 반대로 "낮 고정"도 됩니다. (실측)
- 8개 무대가 **11개 선택지**가 됩니다. 전부 SNK 그림입니다.

## 5. 팔레트 변경 스테이지

### 결론
**됩니다.** 확인 끝났습니다. (실측)

### 확인한 것
- 7판을 처음부터 끝까지 돌렸습니다.
  - 인트로, 싸움, MAX 컷인 뒤, KO, 승리 대사, 저장/불러오기 모두 바꾼 색 유지
  - 캐릭터·HUD 색은 그대로
  - 게임 진행 어긋남 없음
- 타이틀·캐릭터 선택·카드 화면은 안 건드립니다.

### 몇 가지?
- 변형 후보: **밤 · 노을 · 새벽 안개(또는 겨울) · 핏빛 달**
- 8무대 × 4 = 최대 32가지 모습
- 지금 색 공식은 1차안입니다. 무대별로 손보면 더 예뻐집니다.

### 고르는 법 (제안)
- ◀▶ 무대, ▲▼ 변형
- 랜덤은 둘 다 무작위
- 상대마다 "홈 무대 변형"을 줄 수도 있음
- VS 띠 표시 예: «후지산 마을 · 밤»

### 품
- 밤 무대(4번 보너스)와 같은 코어 기능을 같이 씁니다. 합쳐서 3~4일.
- 색 손질: 무대×변형 하나당 0.25~0.5일 (원하면)
