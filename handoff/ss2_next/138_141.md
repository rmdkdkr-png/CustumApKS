## 4. 141 — 치트 창을 열면 시스템이 멈춤

**증상**(에뮬레이터 API 28, 소프트웨어 렌더): «치트 ›»를 누르면 화면이 멈추고 약 1분 뒤 system_server 가 watchdog 에 죽어 시스템이 통째로 재시작.
런처에서(게임 안 켬)도, 게임 안 설정에서도 3번 다 같음. 겉 «옵션» 창은 멀쩡.

**원인**
- 실행 창(`LaunchSheet`)은 아래에 붙은 `WRAP_CONTENT` 다이얼로그 창. 치트 창은 이미 떠 있는 창에 `setContentView` 로 내용을 갈아 끼웠다 →
  창 높이가 바뀌며 창의 위쪽 끝(자리)이 옮겨 감.
- 안드로이드 9 는 창 자리가 옮겨 가면 이동 애니메이션(leash 층)을 만들었다 지운다. 그 뒤 SurfaceFlinger 메인 스레드가
  `handleTransactionLocked → (지운 층 무효화) → Region::orSelf` 에서 돌기만 했다(ANR 덤프의 surfaceflinger 스택).
  system_server `android.anim` 은 `SurfaceControl.closeTransaction` 에서 SurfaceFlinger 를 기다리며 WindowHashMap 잠금을 쥐고 있었고, 다른 스레드가 다 그 잠금에 걸려 watchdog.
- 실기기 안드로이드 9 에서도 같은 길이 날 수 있다(10 이상은 창 이동 애니메이션 경로가 다름).

**고침**(`integ/141_launchsheet.patch`)
- 창은 화면 전체(투명, `MATCH_PARENT`) 하나로 고정하고, 시트는 그 안의 `FrameLayout` 아래(`Gravity.BOTTOM`)에. 치트 창 갈아 끼우기 = 틀 안 내용만 바꿈(`setSheet`)
  → 시트 높이가 바뀌어도 창 크기·자리는 그대로. 시트 바깥(투명한 곳) 탭 = `dlg.cancel()`(예전 «바깥 탭 닫기»와 같음), 시트는 `clickable` 로 탭을 삼킨다.
- 스크롤 높이 상한(겉 50%·치트 58%)을 `onMeasure` 에서 바로 자르는 `cappedScroll`. 예전 `OnGlobalLayoutListener` 는 떼지 않아 내용을 갈아 끼울 때마다 창 관찰자에 쌓였다.

**확인**(같은 에뮬레이터, 로컬 빌드 `.fgdbg`): 런처 «옵션 › → 치트 ›» 열기 · 올카드 «이번만» · 시간 «무한» · 스크롤 · «닫기» → «치트 · 2개 켬 ›» ·
뒤로(치트 → 겉 창 → 닫힘) · 바깥 탭 닫기 · 게임 안 «메뉴 → 설정 → 치트 › → 내 체력 무한 → 적용» — 전부 멈춤 없음, options.txt 에 값 저장.
