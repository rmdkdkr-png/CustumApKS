## 화면
- 덧판(ovplane.c): 게임 160×152 격자 위에 NGPC 규칙(8×8·칸마다 4색·12비트)으로 합성. 코어 RAM/VRAM 안 건드림 → 저장 전 복원 불필요. 잔상 뒤 합성, 바뀐 줄만 올림.
- 결판: 위 띠(VS 띠와 같은 칸 배치, 가운데 낙관 승·패·무·기권·무효) + 오른쪽 칼집(다음 상대 · 재대결/설욕전 n/3 · 새 캐릭터 · 순위·전적 · 그만하기), ◀▶ 무대, OPTION 순위표. 나·상대 LP 숫자와 게이지가 동시에 오르내림(상대 LP 도 기록·순위표와 일치). 일섬·호명 띠·승급 도장은 사건 판만.
- 쉼(랭크 경기 중 OPTION·뒤로·패드 바 목록/종료): 이어하기 · 순위·전적 · 나중에 · 기권(한 줄 안에서 A 한 번 더).
- 서랍: 순위(단상 + 내 주변, 위로 100위까지) · 전적(깃발·최근 10·오늘·LP 흐름·통산) · 설정(결판 연출 보통/짧게/끄기=옛 카드 · 진 판 기본 커서 · 연속 대전).
- 이름표: 줄 24~31, P1 x16~ / P2 ~x142, «계급(색) 닉…». 라운드 시작 2초 진하게. 게임이 그 자리에 그리면(히트 수 P1 x34~63 · P2 x98~127 실측) 숨고 20프레임 비면 다시. 쉼으로 멈춘 그림에 히트 수가 남아 있으면 안 덮음. KO·대사·걸쇠·번쩍 프레임엔 숨김.
- 랭크 경기 중 아래 안내 상자 숨김(직접 고르는 고르기 화면에서만).
- 묻는 창 없앰: «그만하기»·B 두 번 = 리그 켠 채 타이틀. 패드 바·타이틀 뒤로 = 바로 목적지(준비된 경기 기록은 한 번 무효). 일반 판에서 «리그 대전» 칸도 바로. 남긴 창: 덧판을 못 열 때의 옛 창, 롬·저장소 오류, 다른 세션이 연 경기, 리그 화면의 멈춘 경기 기권.
