# 내부 187 (PocketCore feat/framegen-art 8dc945f) — 소리 비는 시간 메우기 · 새 코어 · 작은 고침 둘

186(다른 세션: 타격 이펙트·COUNTER 흰 몸·화면 흔들림) 위에 합침(충돌 없음). CI 39426419293 성공. 182~186 번호는 다른 세션이 먼저 써서, 우리 묶음은 187 하나로.

## 유저가 보게 될 것
- **메뉴 중 배경음 유지**: OPTION 서랍·쉼 메뉴·연습 메뉴·설정 창이 열려 있어도 게임 배경음이 계속(게임은 멈춘 채 — 소리 CPU 만 돌림, 메인 램 그대로).
  닫을 때·열 때 딸깍 없이 짧게 줄였다 키움.
- **4배속 넘김에도 소리**: 리그 넘김(4배속) 동안 게임 소리를 빠르게 이어 냄(전엔 무음).
- **효과음 더**: 연습 메뉴 커서·결정·뒤로, 확인 카드 7종, «상대 찾는 중» 창. 잘리던 «결정» 소리는 끝까지.
- **불러오기 실패**면 «불러오기 실패» 한 줄만(뒤에 «불러옴» 안 뜸).
- 치트 켤 때 자동 저장을 비켜 두면서 베기 색 파일(.state.auto.look)도 같이 옮김 — 남은 파일이 다른 판 색을 덮지 않게.

## 새 코어
코어 패치 `tools/core_patches/zzzzzzzzzzzzz_snd_only.patch`(이름순 맨 끝이어야 함) — 소리 CPU 만 돌리는 `retro_ngp_sndonly_run`, 넘김 나눔 `retro_ngp_snd_div`, `retro_ngp_sndonly_info`.
jniLibs 3종(arm64-v8a · armeabi-v7a · x86_64)은 ss2-sp-core 1cb33c9 + 패치 60개를 여기서 NDK 27.2 로 직접 빌드해 넣음(CI ci-core 와 기능 같음, 컴파일러 판 차이로 바이트는 다름).
앱은 dlsym 으로 찾아 없으면 예전처럼(옛 코어도 그대로 돎).
