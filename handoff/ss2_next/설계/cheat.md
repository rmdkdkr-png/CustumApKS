# SS2 치트 메뉴 — 조사·설계 (Legacito)

요청: «치트 메뉴 추가, 올카드 추가 가능하게».
대상: 사무라이 스피리츠!2 (NGPC, `SAMURAI2v000`) · Legacito(fgint 7a851e6) · 동봉 코어 89860fe · 2026-10-15
작업 폴더: `scratchpad/next/cheat/` (저장소는 안 고침 · 커밋 없음 · 롬에서 나온 그림은 `work/shots/` 에만)

표시: **[실측]** = 이번에 하네스로 잰 것(스크립트·결과는 아래 «이 폴더»), **[0단계]·[연습]** = 리그·연습 문서에 이미 있는 값(다시 재지 않음 — 다만 시제품 시험에서 함께 확인된 것은 [실측]으로 올림).

> 같은 묶음에서 사용자가 남긴 다른 요청(«연습모드는 프레임 발동시간 경직 차 등» = 연습 대전 프레임 데이터)은 연습 쪽 일감이다. 치트는 연습 경기에서 경기 치트를 끄므로(5장) 프레임 데이터 표시와 부딪치지 않는다. 9장의 «게임 속 치트 창»은 연습 메뉴 창 코드를 같이 쓰는 모양으로 설계했다 — 프레임 데이터 창도 같은 틀을 쓰면 한 번에 정리된다.

## 0. 한눈에

- **롬·세이브 파일을 안 고치고 램 쓰기만으로 된다.** 리그·연습과 같은 자리(`retro_run` 뒤, 코어 잠금 안)에서 새 `cheat_tick` 이 작업 램을 고친다.
- **치트 10가지를 실측으로 확인했다**: 올카드(이번만 · 세이브에) · 시간 무한 · 내/상대 체력(무한 · 한 방) · 내/상대 분노 MAX · 상대 가만히 · CPU 세기 · 내 공격력 · 숨은 캐릭터 유가. 시제품 `proto/cheat.c` 를 실제 코어 옆에서 돌려 롬 4판(동봉 한패 · 한패 v1.01 · 한패 h1 · 순정)에서 시험했다(10장).
- **올카드는 두 가지로.**
  - **이번만(기본)**: 캐릭터·검질·카드 고르기 화면과 카드 모음집에 있는 동안만 120칸을 8로 쓰고, 화면을 떠나면 들어올 때 값으로 되돌린다. 게임이 세이브를 쓰는 때(이어하기 끝 = 게임오버 · 스토리 클리어 · 무한 대전 끝 · 설정 저장)에는 램이 늘 원래 값이다 → **세이브 오염 0**(실측: 게임오버 뒤 `.flash` 카드 = 원래 값, 4판 모두). 고른 카드는 되돌린 뒤에도 싸움에 먹는다.
  - **세이브에**: 늘 8 로 둔다 → 게임이 다음에 세이브를 쓸 때 영구로 남는다(실측: `.flash` 120칸 모두 8, 다시 켜면 부팅 때 읽힌 값이 8). 켜기 전에 지금 `.flash` 를 따로 보관한다.
  - 리그의 `LEAGUE_ALLCARDS` 는 랭크전 전용 세이브 폴더에서만 돈다 — 치트와 섞이지 않는다.
- **랭크전·게임 속 리그 세션에서는 치트가 아무것도 안 쓴다**(Java 가 잠그고, C 도 허브 종류를 보고 한 번 더 막는다 — 실측). **연습 경기에서는 경기 치트를 안 쓴다**(연습이 시간·체력·분노·더미를 맡음) — 올카드·유가는 연습에서도 먹는다.
- **화면**: 실행 창(런처)과 게임 안 「설정」 창에 «치트 ›» 고리 하나 → 같은 모양의 «치트» 창(줄 11개). 값은 `options.txt` 의 `pocketcore_ss2_cheat_*` 에 게임별로 남는다. **게임 안에서 바꾸면 다시 열지 않고 바로 먹는다**(JNI 로 값만 넣음). 2단계: 일시정지 위 게임 속 치트 창(연습 메뉴 창 틀 재사용).
- **숨은 캐릭터**: 웹에 이 게임(NGPC)의 숨은 커맨드 기록은 못 찾았다. 램으로 **유가(14)를 P1 로 쓸 수 있다**(스토리 끝·엔딩·카드 공개까지 실측). 간다라(15)는 라운드 끝에서 멈춘다 — 안 넣는다.

## 3. 올카드 — 이번만 vs 세이브에 (결정)

**결정: 둘 다 둔다. 기본(처음 켤 때 값)은 «이번만».**

| | 이번만 | 세이브에 |
|---|---|---|
| 하는 일 | 고르기 창(0x5726 06·08·0A)과 카드 모음집(0x57C6 12) 동안만 8. 들어올 때 보관 → 떠날 때 되돌림 | 부팅 뒤 늘 8 → 게임이 다음 세이브를 쓸 때 남는다 |
| 카드 화면 | 어느 캐릭터든 · 4칸 모두 · 장수 8 | 같음 |
| 카드 모음집 | 120종/960장 | 같음 |
| 세이브 | **안 남음**(게임오버·무한 대전 끝·스토리 클리어 세이브 모두 원래 값 + 게임이 준 상만) | 남음 — 끈 뒤에도 카드가 남는다 |
| 상(카드 공개·8연승) | 진짜 개수에 더해짐(되돌린 뒤에 들어오므로) | 8 에서 받아도 8 |
| 되돌리기 | 끄면 끝 | 켤 때 보관한 `.flash` 로(런처에서만 — 아래) |

왜 기본이 «이번만»인가
- 리그 1단계 문서가 이미 «올카드를 램에 쓴 채 게임오버를 거치면 영구로 남는다»를 위험으로 적었다. 사용자가 모르게 세이브가 바뀌면 안 된다.
- «이번만»은 끄는 순간 원래대로이고, 고른 카드는 그 판 끝까지 먹는다 — 써 보기엔 충분하다.
- 영구로 원하는 사람은 «세이브에»를 고르면 확인 창 하나를 거쳐 남긴다.

«세이브에» 흐름
1. 치트 창에서 «세이브에»를 고르면 확인 창: «올카드를 세이브에 넣을까요? 다음 저장(게임 오버·클리어·설정 저장) 때 120장이 모두 8장이 돼요. 지금 세이브는 따로 보관해요.» [넣기] [그만].
2. 넣기 → Java 가 `saves/<롬이름>.flash` 가 있으면 `saves/<롬이름>.flash.cheatbak` 으로 한 번 복사(이미 있으면 그대로 — 처음 것 보관).
3. native 는 늘 8 을 쓴다. 게임이 세이브를 쓰면 영구. 다음 부팅·모드 고르기에서 다시 읽은 값이 모두 8 이면 `cheat_status[5] = 1` → Java 가 한 번 «올카드가 세이브에 들어갔어요» 알림.
4. 바로 남기고 싶으면 게임 설정에서 값 하나 바꿨다 돌려 «예»(도움말에 한 줄).

되돌리기(«세이브 되돌리기», 런처 치트 창에서만 — 코어가 안 돌 때)
- `.flash.cheatbak` → `.flash` 복사, 그 게임의 오토세이브(`.state.auto`)는 `.state.auto.cheat` 로 비켜 둔다(상태 파일에 플래시 내용이 실려 다니므로 — 0단계). 수동 슬롯 상태도 플래시를 싣고 있다는 것을 확인 창에 한 줄로: «올카드 뒤에 저장한 슬롯을 불러오면 카드가 다시 생겨요».
- `.flash` 를 앱이 직접 고쳐 «지금 바로 영구»로 만드는 길(체크섬이 없어 가능)은 **안 쓴다** — 일지 칸 고르기·칸이 다 찼을 때 동작을 모른다(0단계 열린 문제). 게임 자신의 세이브 길만 쓴다.

리그와의 관계
- 리그 랭크전은 원래부터 랭크전 전용 세이브 폴더(`League.saveDir()`)에서 `LEAGUE_ALLCARDS` 로 돈다 — 그대로 둔다. 치트는 그 세션에서 잠긴다.
- 옛 조작 패치 `ss2_allcards.ips`(원격 색인에만 남은 것: 공장 칸 카드 0xFF·난도 하로 깨짐[0단계])는 치트가 대신하므로 `Settings.RETIRED_MODS` 에 `ss2_allcards` 를 넣는다.

| `cards_tick` | (1) 0x57C6 이 바뀌었고 앞 값이 03 또는 0(= 게임이 방금 세이브를 다시 읽음) → 120칸이 모두 8 이면 `perm_saved`. (2) 세이브에: 0x57C6≠0 이면 memset 8. (3) 이번만: `window` 첫 프레임에 보관 → 매 프레임 8 → 창을 떠나면 되돌림 |
| `yuga_tick` | 0x5726==06 · SCR 2 동안 커서 기억 → 06→08 순간 커서가 60 이고 치트 켜짐이면 `yuga_pick`. 06 으로 돌아가면(이어하기) 다시 판정. `yuga_pick` 이고 0x57D5≠255 면 0x57D5=14 · 0x57D6=검질 |
| `fight_tick` | 시간 → CPU 세기 → 공격력 → 상대 가만히 → (live 일 때) 체력 → 분노. 표 1장 그대로 |
| `league_owns` | 시제품은 공개 함수 셋(`league_hub_status`·`league_hub_dual_status`·`league_status`)으로 판단 — 실제 구현은 league.c 에 아래 accessor 하나를 더한다 |
| JNI | `Java_com_dudu_pocketcore_Emu_nativeCheatSet(int,int)` · `nativeCheatLock(boolean)` · `nativeCheatStatus() → int[16]` (league.c·practice.c 처럼 cheat.c 아래에) |

league.c 에 더할 것(한 함수):

```c
/* 치트가 손대면 안 되는 세션인가 — 게임 속 리그(허브 종류 0, 켜짐) 또는 허브 없이 무장된 랭크전 한 경기 */
int league_owns_session(void)
{
   pthread_mutex_lock(&L_mu);
   int r = (H.st != H_OFF && H.kind == 0) || (H.st == H_OFF && L.armed);
   pthread_mutex_unlock(&L_mu);
   return r;
}
```
(연습 허브는 H_PICK_ME 에서도 `L.armed` 를 세우므로 «armed» 하나로는 못 가른다 — 허브 종류를 같이 본다.)

### 6-다. `native.c` 바꿀 곳

| 자리 | 바꿈 |
|---|---|
| `#include` | `#include "cheat.h"` |
| `load_locked()` 처음 | `cheat_reset_all();` (practice_forget 옆) |
| `unload_locked()` 처음 | `cheat_reset_all();` |
| `nativeFrame()` 진짜 프레임 블록 | `practice_tick(ram, ramsz, in);` 바로 다음 `cheat_tick(ram, ramsz, in);` · 나가기 갈래 `if (ex) { c_reset(); league_practice_return(ex == 2); practice_forget(); cheat_forget(); }` |
| `nativeReset()` | `cheat_forget();` |
| `nativeLeagueHubReturn()` | `cheat_forget();`(리셋 뒤 — 랭크전이라 잠겨 있지만 상태는 비움) |
| `nativeSaveState()` | `practice_before_save(); league_hub_before_save();` 옆에 `cheat_before_save(ram)` — ram = `c_get_memory_data(RETRO_MEMORY_SYSTEM_RAM)` |
| `nativeLoadState()` 성공 | `cheat_forget();` |
| `CMakeLists.txt` | `cheat.c` 추가 |

입력 콜백은 바꾸지 않는다(1단계 치트는 입력을 막거나 더하지 않는다). 2단계 게임 속 창이 들어오면 `cheat_in_block`·`cheat_in_or` 를 `league_in_block | practice_in_block` 식에 더한다.

### 6-라. 프레임 순서(한 진짜 프레임)

```
cb_input_state : (g_input & ~(league_in_block|practice_in_block[|cheat_in_block])) | league_in_or | practice_in_or
retro_run
league_vram → league_palremap_fn → league_tick_hub(ram, in)    ← 대진·허브(리그면 올카드 등)
practice_vram → practice_tick(ram, in)                          ← 연습 경기면 시간·체력·분노
cheat_tick(ram, in)                                             ← 리그면 아무것도 · 연습이면 카드·유가만 · 아니면 전부
practice_take_exit → (리셋) league_practice_return · practice_forget · cheat_forget
```

치트를 가장 뒤에 두는 이유: 리그·연습이 같은 바이트를 쓰는 경우가 생겨도 «치트는 막혔을 때 아예 안 쓴다»로 정리되고, 막히지 않았을 땐 연습/리그가 그 바이트를 안 쓰는 상황이다.

값 번호 바꾸기(Settings.Item 의 `vals` 순서 = native 번호):

```java
static int[] values(Map<String, String> m) {
    int[] v = new int[KEYS.length];
    if ("disabled".equals(m.get(MASTER))) return v;                 // 마스터 끔 = 모두 0
    for (int i = 0; i < KEYS.length; i++) {
        Settings.Item it = Settings.itemOf("pocketcore_ss2_cheat_" + KEYS[i]);   // itemOf 는 지금 private — 패키지 공개로
        v[i] = it.indexOf(Settings.get(m, it));                     // 모르는 값 → 기본값 자리(기존 동작)
    }
    return v;
}
static void push(Map<String, String> m) { int[] v = values(m); for (int i = 0; i < v.length; i++) Emu.nativeCheatSet(i, v[i]); }
```

## 9. 2단계 — 게임 속 치트 창 (일시정지 위)

- **자리**: 연습이 아닌 1인·무한 대전 경기에서 사용자가 Option 으로 게임을 멈추면(0x61D4=1) «PAUSE» 위 HUD 판 줄 4~16 에 «치트» 창. 연습 메뉴 창(F7)과 같은 측정 근거(일시정지 중 게임이 첫째 판·문자 램·스프라이트 램을 안 건드리고 방향·A·B 를 무시함 — 연습 0단계 2-마).
- **줄**: 시간 · 내 체력 · 상대 체력 · 내 분노 · 상대 분노 · 상대 · CPU 세기 · 내 공격력 · 닫기 (올카드·유가는 고르기 화면 일이라 뺌).
- **조작**: ↑↓ 줄 · ←→ 값(바로 먹음) · B·Option 닫기. 열린 동안 Option 은 치트가 받는다(`cheat_in_block = IN_OPT | P_GAME`) → 닫을 때 빌린 타일·칸·팔레트를 되돌린 다음 Option 을 4프레임 대신 눌러 게임을 푼다(연습 M_CLOSING 그대로).
- **코드**: practice.c 의 창 부분(타일 빌리기 `build_candidates`/`pool_get` · 두 띠 그리기 · `window_restore` · 팔레트 13/14)을 `gwin.c`(게임 속 창 틀)로 떼어 연습·치트·(연습 프레임 데이터)가 같이 쓴다. 줄 표는 `{ 라벨 글자열, 값 이름들, get, set }` 배열.
- **글자**: `practice_glyphs.py` 에 음절 추가(치 트 시 간 무 한 보 통 내 체 력 상 대 방 분 노 가 만 히 세 기 게 임 로 아 주 쉬 움 하 중 최 강 공 격 배 닫 — 이미 있는 음절은 같이 씀) → `PG_WANT_WINDOW` 표에 들어감.
- **값 맞추기**: 창에서 바꾼 값은 `cheat_status` 에 더한 «바뀜» 표시로 Java 폴이 읽어 `options.txt` 에 쓴다(실행 창과 어긋나지 않게).
- **유가 글자**: 캐릭터 고르기에서 유가 치트가 켜져 있고 커서가 가운데 칸이면 오른쪽 세로 이름 칸 «쿠로코» → «유가»(리그 `vp_put` 과 같은 방식, 글자 타일 2개).

## 11. 위험 · 열린 문제

| # | 무엇 | 대응 |
|---|---|---|
| R-1 | 확인 안 된 롬 판(조작 패치·다른 한패) | 연습과 같은 판 확인 뒤에만 값을 넣음 |
| R-2 | 이번만 창 판정이 0x57C6·0x5726 에 기댄다 | 데모(0x57C6=03·0x5726=00)·이어하기 화면(0x5726=0C)·설정·타이틀은 창 밖임을 실측. 새 화면을 찾으면 창은 «좁게» 두는 쪽(창 밖이면 카드 화면이 안 뜰 뿐, 세이브는 안전) |
| R-3 | 세이브에: 일지 칸이 다 찼을 때 게임 동작 모름 | 게임 자신의 세이브 길만 쓰므로 원래 게임과 같은 위험 |
| R-4 | 유가 검질은 치트 값으로 정함(유파 선택 화면에서 고른 것과 다를 수 있음 — 가운데 칸은 원래 무작위) | 도움말에 «수라/나찰은 여기서» 를 써 둠. 2단계 세로 칸 «유가» |
| R-5 | 한 방은 가드 깎임에도 KO | 의도(«한 대») — 도움말 |
| R-6 | 무한 체력 + 시간 무한 + 상대 무한 = 판이 안 끝남 | 사용자 선택. 게임 설정·일시정지에서 나갈 길은 그대로 |
| R-7 | `league_owns` 시제품은 매 프레임 자물쇠 셋 | 실제 구현은 accessor 하나(6-나) |
| O-1 | 유가 엔딩 내용(«썩어 가는 어둠 속» 이야기 + 스태프 롤 + 카드 공개)이 유가 전용인지 공통인지 | 화면만 보고 판단 못 함 — 멈춤은 없음 |
| O-2 | CPU 단계 0x5814/0x5815 의 체감 효과 | 배율이 주 효과(실측) — 설명 글을 넘치게 쓰지 않음 |
