# 베기 효과 커스텀? 컬러? — 답

**색은 바꿀 수 있습니다. 내 쪽과 상대 쪽을 따로 정할 수 있어요.** 모양도 바꿀 수는 있지만 그림 작업이 많아서, 하더라도 나중에 하는 게 맞습니다.

베기 효과는 캐릭터 몸과 다른 팔레트를 씁니다. 그래서 지금 캐릭터 컬러를 바꿔도 칼 궤적은 원래 색 그대로입니다. 효과 색은 몸 색과 따로 정해야 하고, 상대별 커스텀 컬러에 «효과 색 한 벌»을 같이 붙이는 방식이면 됩니다.

## 바뀌는 것
- **칼 궤적**: 일반 베기 때 칼끝에 남는 빛 자국. 눈에 가장 많이 띕니다.
- **필살기 이펙트**: 장풍, 불꽃, 번개 같은 기술 그림. 우쿄가 라운드 시작에 던지는 빨간 공 같은 소품도 여기에 들어갑니다.
- **베인 섬광**: 맞은 자리에서 잠깐 번쩍이는 초록 빛. 기본은 «때린 사람 색»이라 내가 베면 내 색으로 나옵니다. 화면에 나오는 시간은 짧습니다.
- 옵션 ① **막기 불꽃, 쓰러졌을 때 머리 위 별, MAX 비오의 빛기둥**: 게임이 이 셋에 같은 색을 써서, 바꾸면 셋이 함께 바뀝니다.
- 옵션 ② **짝꿍**: 나코루루의 매와 늑대, 리무루루의 콘루, 갈포드의 포피와 분신. 기본은 원래 색으로 둡니다.

## 안 바뀌는 것
- 몸 색. 지금처럼 캐릭터 컬러가 따로 맡습니다.
- 체력바, 글자 같은 HUD, 무대 배경, 그림자, 고르기 화면, 승리 대사 화면.
- 불이나 얼음에 맞았을 때 몸이 깜빡이는 상태 이상 색. 일부러 원래대로 둡니다.
- 일부 공용 효과(파란 회오리, 보라 기, 먼지, 회색 연기)는 원래 색으로 남습니다. 지금 코어는 공용 효과 색을 2종까지만 바꿀 수 있기 때문입니다.
- 게임 진행. 같은 입력으로 효과 색을 켠 판과 끈 판을 나란히 돌려 비교했는데, 게임 메모리가 1바이트도 다르지 않았습니다.

## 확인한 것 (실측)
15명 전원으로 19판, 약 18.7만 프레임을 돌렸습니다.
- 각 판은 KO, 승리 대사, 다음 판 시작까지 돌렸습니다.
- 수라와 나찰, 미러전(2P색 포함), 원판 롬, MAX 상태 판도 넣었습니다.

결과는 다음과 같습니다.
- 효과가 아닌 곳에서 화면 픽셀이 바뀐 경우: 0
- 원래 색이 새어 나온 프레임: 0
- 게임 상태가 달라진 경우: 0
- 내 쪽 초록, 상대 쪽 자주로 한 판에 동시에 칠해도 서로 섞이지 않았습니다.

단, 조건이 두 가지 있습니다.
1. **지금 코어 기능만 쓰면 색이 반쯤 바뀐 채로 남는 경우가 있습니다.** 배틀 로드 때 생기고, 한 판에서 867프레임이 이렇게 나왔습니다. 앱이 매 프레임 끝에 한 번 바로잡는 작은 코드를 넣거나, 코어 보완판을 넣으면 해결됩니다. 바로잡기를 넣은 19판은 모두 0이었습니다.
2. **상태 저장/불러오기에 훅 3개가 필요합니다**(저장 전, 저장 후, 불러온 뒤). 훅이 없으면 효과 색을 끈 쪽에서 불러와도 우리 색이 한 라운드 동안 남는 것을 확인했습니다.

알아둘 점도 있습니다. 카즈키 나찰의 불꽃 돌진처럼 몸이 불덩이로 변하는 기술은 그 불덩이까지 테마색이 됩니다. 불꽃 효과라 의도에는 맞지만 눈에 띕니다.

## 모양은?
- **가능합니다.** 효과 그림은 롬에 압축 없이 들어 있어서, 코어가 메모리 속 롬 사본만 고치면 게임이 새 그림을 그대로 씁니다.
  - 실측: 우쿄 궤적 그림 조각 39개를 바꿔 원본과 나란히 돌렸습니다.
  - 게임 진행은 0차이였고, 바뀐 것은 궤적 그림뿐이었습니다.
- **한계**
  - 원래 크기와 칸 수 안에서 다시 그리는 것만 됩니다. 더 크거나 긴 궤적은 안 됩니다.
  - 조각 하나에 3색까지 씁니다.
  - 캐릭터 단위라 미러전에서는 양쪽 모양이 같습니다. 내 쪽만 다르게는 안 됩니다.
  - 캐릭터 한 명의 궤적만 해도 그림 조각이 50~170개입니다.
  - 아직 못 본 기술의 그림은 원래대로 남습니다.
- **권장**: 색을 먼저 하고, 모양은 «특별 스킨» 정도로 나중에 합니다.

## 프리셋 예 (속 / 중간 / 가장자리)
| 이름 | 느낌 |
|---|---|
| 청염 | 흰빛 속, 하늘빛 파랑, 짙은 파랑 테두리 |
| 흑염 | 연보라 속, 짙은 자주, 거의 검정 테두리 |
| 금빛 | 연노랑 속, 금색, 갈색 테두리 (원래 궤적이 노란 우쿄 등은 원래와 비슷해서 그 캐릭터에선 숨김) |
| 핏빛 | 분홍빛 속, 진홍, 검붉은 테두리 |
| 벚꽃 | 아주 연한 분홍, 분홍, 자두색 테두리 |
| 비취 | 박하빛 흰색, 비취 초록, 짙은 녹색 테두리 |
| 뇌광 | 흰색, 노랑, 보랏빛 테두리 |
| 서리 | 흰색, 옅은 얼음빛, 회청색 테두리 |

내 색 고르기도 같은 방식입니다. 세 색만 정하면 캐릭터마다 원래 효과 색의 밝은 순서대로 맞춰 들어갑니다.

## 품 (추정)
- **색**(편별, 상대별): 3일 안팎이고, 실기 확인은 따로입니다.
  - 앱 쪽 작은 모듈(시제품 약 180줄)
  - 롬 색 표 생성기
  - 설정 화면(프리셋, 내 색)
  - 상대 프로필에 «효과 색» 한 칸
  - 저장 훅 3개
- **코어 보완판**(선택): 반나절~1일에 전 플랫폼 코어 재빌드가 따릅니다.
  - 앱 쪽 바로잡기 없이도 깨끗해집니다.
  - 공용 효과 색 칸이 넉넉해져서 파란 회오리 같은 것도 바꿀 수 있습니다.
- **모양**: 코어 쪽 작업은 하루 정도이고, 대부분은 그림 작업입니다. 캐릭터 하나 궤적에 하루~며칠이 듭니다.

## 아직 안 한 것
- 실기(안드로이드) 확인
- 런어헤드와 프레임 생성을 켠 화면을 픽셀 단위로 보는 것
- 엔딩과 이어하기 카운트다운 화면
- 기술 중에만 잠깐 쓰는 효과 색의 전체 목록. 목록에 없는 기술 효과는 원래 색으로 남습니다.
