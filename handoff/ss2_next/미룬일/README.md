# 미뤄 둔 일 (2026-10-17)

## 베기 효과 색 프리셋 + 셀렉창 아이콘 — 유저 결정까지 끝, 구현은 멈춤
- 유저: «베기 효과는 몇 가지 두고 커스텀은 미뤄 두고, 셀렉창에서 작은 아이콘으로 예시 보여 주면서 교체» · «2P색 기능은 빼고 A+B 에 베기 컬러 설정».
- 캐릭터 고르기 버튼(정해진 것): A = 결정 · B = 결정(보통 색, 플레이어 2P색 없음) · OPTION = 몸 컬러 · **A+B = 베기 색 바꾸기**(아이콘·이름 바뀜, 결정 아님). A/B 를 누르면 4~5프레임 기다려 다른 버튼이 같이 오면 바꾸기. 게임이 같은 캐릭터 거울전에서 CPU 에 주는 자동 2P 팔레트는 그대로. 안내 글 «A 결정 · OPTION 컬러 · A+B 베기 색». pref.main b2p 는 늘 0.
- 범위: 내 쪽만(궤적·필살기 +2~+4 와 알려진 +1, 내가 벤 상대의 섬광 팔레트). 상대·딸린 동물·B7(가드 불꽃·별·MAX 기둥)은 원래 색. 프리셋: 원래 색 + 청염·흑염·금빛·핏빛·벚꽃·비취·뇌광·서리 중 6개 안팎.
- 기술: 코어 안 고침 — 동봉 코어 palremap + native 사후 보정(시제품 scratch `u162/proto` fx.c), look.c 의 RM_IDX 표에 합치기, 저장/불러오기 훅 셋. 근거: `../조사_베기효과/README.md`.
- 다시 시작: workflow 스크립트 `impl-slash-fx-presets`(이 세션 기록) 또는 위 내용으로 새로.
