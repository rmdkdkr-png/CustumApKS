# 181 소리 비는 시간 조사 (u181s)

대상: 배포한 181 = `w181` (w181-ship e0ee8d2) — 읽기만, 커밋 없음.
방법: 기기 흉내(sim — 진짜 EmuActivity + 진짜 native.c + 진짜 코어 core181 + 가짜 AAudio 를 vsync 마다 «소리 카드처럼» 가져감)로
랭크 한 바퀴·연습 한 바퀴를 처음부터 끝까지 녹음하고, 호스트 코어에서 «소리 CPU 만 돌리기» 등을 실험했다.

## 0. 한눈에 (유저에게 그대로 말해도 되는 것)

**효과음은 들어가 있다(180부터).** 리그 덧판 화면은 모두 소리가 난다 — 대기(타이틀 OPTION) · 서랍(순위·전적·리그·설정 탭) · 리그 탭 «내 이름» ·
이름 카드 단추 · 경기 중 쉼 · 기권 확인 · 리그 나가기 패 · 결판 띠(▲▼·◀▶ 무대·A·B) · 결판 띠에서 연 서랍. 시험에서 누름 49 번 모두 맞는 소리가 났다(49/49).
**효과음이 없는 곳**: 연습 대전의 연습 메뉴(OPTION 창 — 시험 9 번 모두 소리 없음), «상대 발견!» 찾기 겹창, 바(아래 메뉴 줄)·설정 창·치트 창·컬러 만들기·리그 화면(안드로이드 화면들), 확인 카드 7 개(«기권할까요?» · «리그 경기 중» · «끝나지 않은 경기가 있어요» 등 — 카드 중엔 이름 카드만 소리).

**소리가 비는 시간이 많은 건 맞다.** 랭크 4 판을 도는 293 초 중 130 초(44%)가 게임 소리 없음. 원인은 둘로 갈린다:

| 누가 만든 조용함 | 어디 | 한 판에 얼마나 | 합계(293 초 중) |
|---|---|---|---|
| **사무쇼2 원래** (코어가 소리를 0 으로 냄) | 라운드 사이 · KO 뒤 ~ 승리 대사 · 라운드 시작 전(VS 띠·«1회전» 콜) · 타이틀 메뉴 | 라운드 끝→다음 라운드 10.4 s 중 ~9 s · 결판 KO→결판 띠 10.9 s 중 ~9.7 s · 라운드 전 2.4 s | 85 s (빈 시간의 65%) |
| **앱이 만든 것** — 결판 띠 | 승리 대사 끝 걸쇠로 게임을 세움 | 띠에 머무는 만큼(시험 2~5 s) | 17 s |
| **앱이 만든 것** — 덧판이 게임을 세움 | 대기 · 쉼 · 서랍 · 기권 확인 | 여는 만큼 | 23 s |
| **앱이 만든 것** — 4배속 자동 진행 | «상대 발견!» 뒤 고르기·이야기를 4배로 넘기는 동안 소리를 버림 | 1.05 s (그 직전 «결정» 소리도 115 ms 에서 잘림) | 4 s |

연습 한 바퀴(77 초)는 24.6 초가 비는데 전부 게임 원래(로고·타이틀 메뉴·라운드 전). 연습 메뉴는 게임 자체 PAUSE 위라 **배경음이 계속 난다**.

**중요한 발견 하나**: 사무쇼2 원래 PAUSE(OPTION)는 **배경음이 계속 난다**(호스트에서 잼: 멈추기 전 RMS 2393 → PAUSE 중 2335).
앱의 쉼·서랍은 코어를 통째로 세워서 **원작보다 더 조용하다** — 이건 고칠 수 있다(아래 ①, 실험으로 됨).

**채우는 방법 — 추천 순서** (자세한 비용·위험은 §5)

| | 무엇 | 실험 결과 | 비용 | 위험 |
|---|---|---|---|---|
| ① | 쉼·서랍·대기 동안 **소리 CPU(Z80)만 계속 돌리기**(메인 CPU 는 멈춘 채) — 원작 PAUSE 처럼 배경음 계속 | 됨: 10 초 동안 원래 곡이 그대로 이어짐(같은 음 비율 0.99 · 지연 0) · 게임 램 0 바이트 바뀜 · 다시 돌리면 경기 그대로 | 코어 패치 ~50줄 + native.c ~30줄 | 낮음~중간 |
| ② | **뚝 끊김 없애기**(쉼을 열 때 소리가 한 샘플에 0 으로 떨어져 «딸깍» · 울림 꼬리도 잘림) — 10~20 ms 줄이고 울림 꼬리 1 초 내보내기 | 잼: 쉼 여는 순간 직전 RMS 1683 · 마지막 샘플 1217 → 0 | native.c ~30줄(앱만) | 낮음 |

| ⑥ | 라운드 사이·KO 뒤의 원래 조용함 | 원작 박자 — **그대로 두기를 권함** | — | (채우면 높음) |

## 1. 어떻게 쟀나

- 하네스: `u181s/sim` = u181/v168/sim(최신 SimTest·받침) + u181/s/sim(소리 받침: 가짜 AAudio · audio_cb 그대로) 합침.
  native.c 는 소스 그대로 넣고(`c/nhj_native_tap.c` 가 `#include "native.c"`), 같은 번역 단위 안에서만
  · 코어 소리 콜백 앞에 끼움(`c_set_audio_sample_batch` 를 함수형 매크로로 바꿔 끼움) → **코어가 낸 소리**(league_mute 로 버리기 전)를 vsync 마다 잼
  · 정적 상태 읽기(g_paused · g_loaded · 스트림 · league_mute/ff · 걸쇠 · ov_hold · 고리 채움).
- 장면 `j/GapSim.java`: vsync 마다 한 줄(스피커 출력 RMS·꼭대기, 메뉴 효과음 몫, 코어 소리, 상태, 허브·덧판·찾기 겹창) → `out/<장면>/*.csv` + 표시(marks) + 효과음 확인(sfx) + WAV.
  - `ranked`: 허브 → 타이틀 5 s → 대기(▼▲ · 서랍 · ▶ 탭 · 리그 탭 · «내 이름» · 이름 카드 길) → «상대 찾기» → 판 1(조작 4 s 뒤 쉼 → 서랍 → 쉼 → 이어하기) → KO → 대사 → 결판 띠(▼▲◀▶) → «다음 상대» → 판 2 → «재대결» → 판 3 → «다음 상대» → 판 4(조작 4 s 뒤 바 «리셋» → 타이틀 4 s → A 이어 하기 → 3 s 뒤 설정 바뀜 = 새 창으로 다시 올림 → 끝까지) → 결판 띠.
  - `prac`: 일반 판(«리그·연습» 켬) — 전원 → 타이틀 → 셋째 줄 «연습 대전» → ①②③ → 연습 경기 → 연습 메뉴(▼▲ · B 닫기) → 연습 메뉴 «상대 고르기» → 다시 경기 → «타이틀로».
  - `extra`: 덧판 나머지 — 대기 «리그 나가기» 패 · 쉼 «기권» 확인 · 결판 띠에서 서랍 · 결판 «그만».
  - 판정: 효과음 = 누른 뒤 25 vsync 안에 uisfx 종류가 기대와 같고 메뉴 몫 꼭대기 > 500.
- 조건: JUE 롬(앱 리그 sim 기본) · dev 옵션(프레임 생성 · 런어헤드 2 — 사용자 기기 설정) · 60 Hz · 음색 다듬기 기본(켬 · 배경음만 · 다섯 값 50).
  경기는 CPU 대 CPU, 판 1~3 은 라운드마다 4~5 초 뒤 P2 체력 0(KO 를 빨리), 판 4 는 설정 다시 올린 뒤 손질 없이 끝까지(라운드 ~40 s — 경기 중엔 곡이 계속 남).
- «빈 시간» = vsync(16.7 ms) 단위 RMS 40 아래(≈ −58 dBFS · 곡은 RMS 1000~2500) 가 0.25 s 넘게. «게임 소리» = 출력에서 메뉴 효과음 몫을 뺀 것.
- 분석: `analyze.py`(빈 구간 + 원인) · `segs.py`(구간을 소리/빔 조각으로) · `cuts.py`(WAV 에서 뚝 끊김).

### 2-3 뚝 끊김 (`cuts.py` — 0 이 50 ms 넘게 이어지는 자리 75 곳 중)

- **쉼을 여는 순간**(경기 중 OPTION): 직전 20 ms RMS 1683 · 마지막 샘플 1217 → 다음 샘플 0. 코어가 멈추면 고리(~20 ms)가 다 나가자마자 0 이 된다 — «딸깍» + 음색 다듬기 울림 꼬리(최대 1 s) 통째로 잘림. extra 장면에서도 같음(RMS 1874 · 마지막 825).
- 4배 자동 진행 들어갈 때: 결판 «결정» 소리가 4 ms 줄임으로 끝(딸깍 없음) — 대신 538 ms 짜리가 115 ms 만 남(사무쇼2 도 장면이 바뀌면 0xFF 로 결정을 33~101 ms 에 끊으니 원작과 비슷).
- 바 «리셋» → 타이틀: 코어가 0 을 내며 계속 돌아 울림 꼬리가 1.5 s 자연스럽게 빠짐(대조).
- 나머지 70 곳: 게임이 스스로 조용해진 자리(직전 샘플 ≤ 1 — 자연 감쇠).

## 5. 채우기 제안 — 자세히

### ① 덧판이 코어를 멈춘 동안 소리 CPU 만 돌리기 (쉼 · 서랍 · 기권 확인 · 대기)

- native.c `nativeFrame`: 지금은 `pace_steps(..., g_paused || ... || ov_hold())` 가 0 을 돌려 아무것도 안 돈다. hold 일 때 코어 fps 박자(따로 셈)로 `c_sndonly(1)` 을 CORE_LOCK 아래 부르면
  소리가 `cb_audio_batch`(음색 다듬기 → 늘림 → 고리) 로 그대로 간다. 내보내기가 없는 옛 코어면 지금처럼 조용.
- 어디에 걸지: ov_hold(쉼·서랍·확인·대기) 먼저. g_paused(바·설정 창·카드)는 고르기. 결판 띠(걸쇠)·대기(타이틀)는 게임이 원래 조용한 자리라 이것만으론 여전히 조용 → ③ 과 함께.
- 덧판이 열린 동안 곡을 −6 dB 쯤 낮추면 메뉴 효과음이 또렷(원작 PAUSE 는 안 낮춤 — 취향).
- 위험: 쉼 중에 만든 체크포인트(나중에·리셋·설정 다시 올림)엔 Z80 이 앞선 상태로 담김 — 이어 하면 곡이 그 자리부터(문제 아님). 코어 안 런어헤드는 retro_run 안에서 저장·되돌리므로 그 사이 Z80 진행과 안 부딪힘.
  SfxSim 정답 «쉼 — 출력이 정확히 0» 은 바꿔야 함. 3 ABI 코어 다시 빌드.

### ② 뚝 끊김 없애기 (앱만)
- `audio_cb` 에서: hold·mute 로 고리가 마를 때 남은 샘플에 10~20 ms 줄임을 걸고, 0 뒤 다시 날 때 첫 10 ms 키움.
- 멈춘 동안 `fx_apply` 를 0 입력으로 ~1 s 더 돌려(코어는 안 돌림) 울림 꼬리를 고리에 넣기 — 리셋 때 이미 그렇게 자연스럽게 빠지는 걸 확인(1.5 s).
- ① 을 하면 쉼에선 끊김 자체가 없어지고, ② 는 결판 걸쇠·스트림 닫힘·설정 다시 올림 같은 나머지 자리에 남는다.

### ③ 대기·결판 띠에 곡 넣기 (① 위에 곡 명령)
- 코어: `retro_ngp_snd_cmd(v)` 2줄(0xBC 쓰기 + Z80 NMI — 게임과 같은 길).
- 대기(타이틀 위, 원래 무음): 열 때 0x03 → 고르기 곡(실험으로 확인), 닫고 타이틀로 돌아갈 때 0xFF(원래처럼 조용). «상대 찾기»를 고르면 게임이 스스로 다음 곡을 올린다.
- 결판 띠: 그 자리 Z80 램엔 «세 번째 곡» 이 올라 있다(실험). 무대 곡(또는 고르기 곡)을 틀려면 그 곡이 올라 있을 때 Z80 램 0x7000~0x7FFF(4 KB — 앱이 이미 시스템 램으로 읽고 쓰는 범위)를 떠 두었다가
  결판 띠에서 되돌려 넣고 0x03. 결판 띠 뒤엔 늘 리셋·허브 돌아가기(다음 상대·재대결·그만·새 캐릭터)라 바꾼 Z80 램이 게임으로 새지 않는다(걸쇠는 리셋 전까지 한 프레임도 안 돌림).
- 위험: 닫을 때 끄기를 빠뜨리면 원래 조용한 타이틀에 곡이 남는다 · «배경음악 끔» 롬 판은 곡 데이터가 비어 조용(그대로 두면 됨) · 체크포인트와 섞이지 않게(대기·결판 띠에선 체크포인트를 안 만듦 — 확인 필요).

### ④ «상대 발견!» 뒤 4배속 자동 진행(1.05 s) 소리
