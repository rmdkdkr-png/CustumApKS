유저 요청: «랭크매치 실제처럼 무한으로 매칭 / 프로필 사진 등 데이터풀 만들어서 진짜처럼».
PocketCore `feat/framegen-art` `7b35ba2`(146 `f8049ac` 위 커밋 하나, 패치 `147_ranked.patch`) (CI «Legacito 시험», 릴리즈 `fgtest`). 조사·설계 전문: `../설계/ranked.md` · `../설계/profile.md`.

## 1. 사용자에게 보이는 것

**게임 속(타이틀 셋째 줄 «리그 대전»)**
- A = **상대 찾기**. 게임 그림 위에 «상대 찾는 중… 0:07 · 배치 경기 2/5 · 0승 2패 · 오늘 36,743명 접속 · 취소 (B)».
  기다림은 내 실력대 사람 수에 따라 1~12초(상위권일수록 길다).
- **상대 발견!** 카드: 픽셀 아바타 · 닉네임 · 티어 ★ · LP(무쌍이면 MR) · 칭호 · 지역 · 캐릭터·검질 · 한마디 ·
  «첫 대전 / 라이벌 / 설욕전» 꼬리표 · 상대전적 · 이기면/지면 LP 어림 · 배경(◀▶). 3초 뒤 자동 대전(대전 A · 나가기 B).
- 고른 상대는 카드 전에 **«잡힘»**으로 저장 — 카드에서 나가도(앱을 꺼도) 붙을 때까지 같은 상대(쉬운 상대만 골라 받기 막기, 하루 지나면 풀림).
- 대전 → «상대 선택» 없이 바로 내 캐릭터 고르기 → 경기(CPU 세기 = 상대 MMR 로 단계·상한·공격/방어 배율·바닥 5개 손잡이).
- 결과 카드: 승리/패배/기권패 · 티어·LP 변화(배치 중엔 «배치 3/5») · 보너스(연승·설욕·오늘 첫 승) · 승급/강등 위기/강등 · 상대전적 ·
  **[다음 상대] [재대결] [그만]**. 다음 상대 = 리셋 뒤 바로 찾기, 재대결 = 같은 상대·같은 손잡이(이어서 3판까지).
- 경기 중·고르기 중 확인(그만두기·나가기·보류 안내)은 **창이 아니라 게임 화면 안 카드**(아래 5장) — 세로 화면은 엄지 자리(아래), 가로는 가운데.

**리그 화면(순위표)** — 탭 «순위표 / 최근 경기 / 라이벌 / 규칙»
- 내 카드: 티어·★·LP 막대(다음 ★·승급까지) · 강등 위기 · 전국 N위 / 39,899명 · 시즌 1 · 통산·연승.
- 순위표: 위 100 · 내 주변(배치 중엔 «배치를 마치면 내 주변 순위가 나와요»). 줄마다 아바타·닉네임·캐릭터·승률·LP/MR. 줄을 누르면 프로필.
- 최근 경기: «기권패 · 배치» / «승 2:1 · +95 LP» / 무쌍은 «+13 MR».
- 라이벌: 예전 12명 + 자주 만난 상대. 규칙: 티어 표·LP 규칙.

## 2. 규칙 한눈에(`RankCore`)

- 세상: 설치마다 씨앗 하나(`ranked.seed`) → 39,899명(id `p%03d%04d`, MMR 정규분포) + 예전 12명(o01~o12, 라이벌). 같은 씨앗·같은 날 = 같은 순위표.
  날마다 조금씩 움직인다(오늘 MMR = 기본 + 날짜 흔들림 + 나와의 경기로 바뀐 값).
- 티어: 수련생 0 · 낭인 500 · 무사 1250 · 검객 2250 · 검호 3500 · 달인 5000 · 검성 6750 · **무쌍 9000**(MR — 엘로, 강등 없음). 각 ★1~5.
- MMR: 엘로, K = 배치(5판) 64 → 20판까지 40 → 28. 배치 끝 LP = lpOfMmr(MMR) − 300.
- LP: 이김 (50 + 100·(1−기대)) × (1 + 0.5·g), 짐 −(30 + 100·기대) × (1 − 0.4·g) — g = MMR 이 LP 보다 위인 정도(LP 가 실력을 따라감).
  수련생은 안 깎이고 낭인은 반. 티어 바닥에서 한 번 버팀(«강등 위기!»), 또 지면 강등. 보너스: 3연승부터 +10~40 · 설욕 +20 · 오늘 첫 승 +30.
- 매칭: 내 MMR ± σ(배치 90 → 60) 근처에서 최근 상대 빼고, 12% 는 라이벌·설욕전. 상대 MMR → CPU 손잡이(`RankCore.knobs`, 실측 E1~E6 — 설계 2장).
- 예전 리그 이어받기: 정산 5판 이상이면 예전 점수 = MMR 로 배치 없이(K 는 40부터), 12명 상대전적 → players, 옛 칸(me·opps·matches)은 그대로.

## 4. 검토

**1차(에이전트 22, 17건 모두 확인 — 고침)**
1. 카드의 «대전»을 손가락으로 누른 직후 폴링이 다음 게임 프레임보다 먼저 오면 찾기를 다시 열어 경기가 깨짐(약 5%) → `rankGoAt`(허브가 6 을 떠날 때까지 2초 기다림).
2. 상대 MR 을 무쌍 상대일 때만 적어 무쌍인 내가 이겨도 MR +0 · 지면 −32 → 모든 상대의 MR 을 적고, 안 적힌 옛 경기는 MMR 로 계산.
3. 순위표 줄 LP 가 나와의 경기로 바뀐 LP(lp_adj)를 빼먹어 프로필·카드와 다름 → `Book.lpAdj`.
4. 내 주변(150위 밖)에서 무쌍 내 줄 «MR 0» · MR 순서 뒤섞임 → 내 MR · 열쇠(LP/MR)로 정렬 · 가운데 맞춤.
5. 결과 창 무쌍 판정을 MR 변화로 해 무쌍 진입 판이 «MR 0 → 1530» → 시작 때 무쌍이었나로. 최근 경기 줄도 무쌍은 MR.
6. 예전 리그에서 넘어온 사람이 배치 K 64 를 받음 → games 5 부터(K 40).
7. «오늘 접속»이 전체 인원보다 많은 날 → 92~98%.
8. 배치 중 내 주변이 LP 0 수련생 사이에 내 순위를 보임 → 안내 글.
9. 랭크 경기를 위쪽 `matches` 에 넣어 같은 폴더의 예전 판이 열린 랭크 경기를 못 끝내고 리그가 막힘 → `ranked.matches`.
10. 업데이트 전 예전 경기를 끝낸 결과 카드의 «재대결·다른 상대»가 랭크 판에선 경기를 못 만듦 → «랭크 매치»(바로 찾기).

**2차(이번 고침 + 확인 카드 — 에이전트 12, 8건 중 4건 확인 — 고침)**
1. 확인 카드가 스틱·HAT 십자를 안 받아 패드만 쓰는 사람은 첫 단추(계속)만 누를 수 있었고, 스틱 입력이 카드 아래 게임·바로 갔다 → 카드가 받고 삼킴.
2. «다음 상대» 직후 찾기 상태가 된 순간 뒤로 → 나가기 카드 위로 찾기·상대 카드가 그려지고 멈춘 채 자동 대전 → 카드·멈춤 바가 떠 있는 동안 찾기 시계를 멈춤
   (닫으면 이어서 — 자동 대전 3초·대전 확인 2초도 그만큼 밀림). 카드 위에 카드가 뜨면 겹쳐 쌓음(먼저 카드의 닫힘 리스너가 경기를 풀지 않게).
3. 예전 판이 랭크 경기를 못 보니 두 판이 끝나지 않은 경기를 하나씩 남길 수 있다 → 허브 시작 때 대진 전 경기는 모두 무효, 끝나지 않은 경기는 이어 하기.
   새 경기를 못 만드는 까닭이 끝나지 않은 다른 경기면 막다른 안내 대신 카드 «이어 하기(리그 판 다시 열기) / 기권 / 나중에». `markInterrupted` 는 두 목록 모두.
4. MR 1500 아래 무쌍이 무쌍 아닌 사람보다 낮게 매겨지고 내 주변 위쪽이 비었다 → 분포 자리(`centre`)를 무쌍 경계 아래로 안 내림.
버린 것 4: 썸네일 카드(지금 바에 «찍기» 단추가 없어 못 남) · 대전 확인 2초 경합(한 프레임 창 — 2번 고침으로 충분) · 옛 위쪽 랭크 경기 옮기기(내놓은 적 없는 시험판 자료).

## 5. 게임 중 확인 창 → 화면 안 카드 (SurfaceFlinger 멈춤)

- 증상(에뮬레이터 API 28, 소프트웨어 렌더): 경기 중 뒤로 → «리그 경기 중» 확인 창이 뜨는 순간 화면이 멈추고, 약 1분 뒤 system_server 가 watchdog 으로 죽어 시스템 재시작.
  SurfaceFlinger 메인 스레드가 `handleTransactionLocked → (지운 층 무효화) → Region::orSelf` 에서 돌기만 함(`debuggerd -b`) — 141 치트 창과 같은 스택.
- 같은 일이 세 번: 10-13 리그 허브에서 뒤로(watchdog 기록 남음) · 10-15 치트 창(141 에서 창 크기 고정으로 고침) · 이번 랭크 경기 중 뒤로.
- 매번 나지는 않는다: 같은 허브 확인 창을 15번 여닫아도 안 남(토스트를 띄운 채로도). 확인 창이 뜰 때 상태 표시줄·창 자리는 그대로였다 —
  창 이동 애니메이션 가설은 이번 경우엔 아님. 근본 원인(어느 층의 경계가 뒤집히는지)은 못 잡았다.
- 고침: `EmuActivity` 의 AlertDialog 7개(그만두기 · 시작 전 그만두기 · 허브 나가기 · 보류 안내 · 이어할 수 없음 · 리그를 못 엶 · 썸네일 지정)를
  게임 화면 안 덮개 카드 `Ask` 로. 창을 새로 만들지 않으니 창 애니메이션 층(leash)·어둡게 깔기 층·포커스 이동이 없다.
  뒤로 = 취소(취소 못 하는 안내는 그대로) · 바깥 탭은 삼킴(실수로 닫히지 않게) · 패드 ◀▶ 고르고 B·START·확인으로 누름, A·뒤로 = 취소(바 메뉴와 같은 키) ·
  단추를 누르면 리스너 다음에 닫힘(AlertDialog 와 같은 차례) · 회전하면 자리 다시.
- 확인(같은 에뮬레이터): 랭크 경기 중 뒤로 → 카드(창 2개 그대로: 게임·런처) → 기권 → 결과 카드 · 허브 나가기 카드 → 순위표 — 멈춤 없음.
- 실기기 안드로이드 9 에서 같은 일이 나는지는 모름(실기기 보고 없음). 리그 화면(`LeagueActivity`, GL 없음)의 프로필·결과 창은 그대로 창.
