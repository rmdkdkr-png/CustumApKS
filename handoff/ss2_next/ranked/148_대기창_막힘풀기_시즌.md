# 랭크 대기창 · 리그 언제든 다시 (Legacito 내부 148)

유저 요청: «랭매 대기때 뭐 할지도 결정해야겠네 대기창이 있다거나» · «리그모드는 언제든 다시 할 수 있게 방도를 마련».
PocketCore `feat/framegen-art` (올리는 중 — 마지막 확인 뒤, 147 `7b35ba2` 위 커밋 하나). 설계 전문: `../설계/대기창_언제든/`(조사 3 · 안 3 · 심사 2 · `spec_148.md`).
native(C)는 안 바꿨다 — 자바만.

## 1. 사용자에게 보이는 것

**대기창**(«상대 찾는 중» 작은 상자 → 게임 그림을 덮는 대기창)
- 머리: «상대 찾는 중… 0:03 · 예상 0:07» — 예상은 처음에 정하고 늘지 않는다(카드는 제때 또는 조금 일찍).
- 릴: 매칭이 실제로 훑은 후보(최대 8명)의 아바타 · «닉 · 티어»가 돌다가 끝 두 칸 느려지며 내 상대에게 멈춘다(카드 0.5초 전).
  잡힌 상대면 «기다리던 상대에게 가는 중… 곧 만나요».
- 내 자리: 티어 · LP(무쌍 MR) · 다음 ★/승급까지 막대 · «강등 위기!» · 배치 중엔 «배치 경기 n/5».
- «오늘 W승 L패 · ±N LP ●○·» · 한 줄 알림(«N연승 중!» / «다음엔 이겨요» / «첫 승 보너스 +30 남았어요»).
- 팁 한 줄(실측 사쇼2 지식 12개, ▲▼ 로 넘김 — 고른 상대 이름은 안 나옴) · 스테이지 ◀▶(찾는 중에도) · [취소 (B)] · 도는 줄(«오늘 N명 접속» 등).
- 기다림: «보통» 4~9초(저녁 조금 빠르게 · 새벽 조금 늦게, 15초까지) / «빠르게» 2~6초(리그 화면 규칙 탭). 잡힌 상대 1.2~2.4초.
- 화면이 낮으면(가로·작은 폰) 줄을 접는다(팁·오늘 → 알림·도는 줄).
- **상대는 보인 뒤에만 잡힌다**: 릴이 상대에게 멈추는 순간(또는 카드) 잡히고, 그 뒤 B·뒤로·홈은 «나가기»(다음에 같은 상대).
  멈추기 전에 그만두면 아무도 안 잡힌다. 카드가 뜬 뒤 0.4초는 A·탭을 안 받는다(못 본 상대를 받지 않게). 카드에 «기다린 시간 0:07».

**언제든 들어가기**
- 일반 게임 멈춤 바 끝 칸 «리그 대전 / 랭크 매치»(싸우는 중에도 뒤로 → 한 번). 자동 저장이 꺼져 있으면 한 번 묻는다.
  «리그·연습» 옵션이 켜져 있으면 조작 패치가 든 롬에서도 나온다(리그 판은 자기 롬 사본을 쓴다).
- 런처 사쇼2 카드 옵션 창 «랭크 매치 바로 가기 ›»(«리그 순위표 ›» 위) → 바로 대기창.
- 리그 판 나가기 카드 «어디로 갈까요?» [계속] [내 게임으로] [순위표] [목록으로] — «내 게임으로» = 하던 게임(자동 저장 자리)으로.
  캐릭터 고르기·대진 전에도 [계속] [타이틀로] [내 게임으로] [순위표].
- 리그 화면 버튼은 늘 보인다(상태에 따라 «랭크 매치 하러 가기» / «멈춘 경기 이어서 하기» — 이어 하기도 게임 속 리그로 들어가 결과 뒤 [다음 상대]).

**절대 안 막히기**(막힘 카드마다 그 자리 해결 — 모두 화면 안 카드)
- 앱이 멈춰(체크포인트 없음·못 불러옴) 이어할 수 없는 경기: «멈춘 경기를 이어할 수 없어요» [무효로 닫고 계속](LP·전적 그대로 → 바로 찾기, 같은 상대) [기권하고 계속] [리그 화면으로].
- 롬이 바뀐 경기: «다른 롬으로 바뀌었어요»(원래 롬이면 이어 할 수 있음) [기권하고 계속]. 앱이 바뀌어 롬·코어가 안 맞는 경기: «앱이 바뀌어 이어할 수 없어요» [무효로 닫고 계속].
- 기권은 늘 한 번 더 묻는다(«기권할까요? … (LP -N)», 수련생은 LP 줄 없음).
- 저장소: «리그 기록 파일을 못 읽어요 / 폴더에 쓸 수 없어요» [다시 확인] [권한 설정 열기]. 결과 저장 3번 실패: [다시 시도] [권한 설정 열기] [나중에 정산하기](체크포인트로 남겨 다음에 정산).
- 잡힌 상대: 보류(난도 불일치 등)면 풀리고, 고르기에서 앱이 두 번 내려가면 풀린다(스스로 뒤로 나간 건 안 셈). 하루 지나면 풀림(그대로).
- 리그 화면을 열 때 첫 라운드 전에 멈춘 경기는 무효로 정리.

**처음부터**(리그 화면 규칙 탭 «시즌 · 기록»)
- «새 시즌 시작»: LP 를 배치 착지점 쪽으로 반(예: 3,920 → 3,310) · 승패·연승 0부터 · 실력 점수(MMR)·상대 전적은 그대로. 배치 중엔 숨김.
- «처음부터 다시»: 배치 5판부터 · 상대 전적도 처음 · 같은 세상(같은 씨앗).
- 둘 다 먼저 보관 파일 `league/archive/ranked-s<N>-<season|restart>-<시각>.json` 을 쓰고 읽어 확인한 뒤 바꾼다(실패하면 되돌리고 보관 파일 지움). «지난 시즌» 줄 · 통산 승패 · «지난 시즌 최고» 판.
- 끝나지 않은 경기가 있으면 못 함(먼저 정리). «시즌 1» 고정 글자 → 실제 시즌.

## 3. 만든 길과 검토

1. 설계 워크플로(9 에이전트): 코드 지도 둘 + 실제 게임 조사 → 안 셋 → 심사 둘 → `spec_148.md`.
2. 구현 1단계(순수 칸 — RankCore·League·RankTips·JVM 시험) → 독립 점검 8건(6 고침).
3. 구현 2단계(세 갈래 병렬 — 게임 화면 / 들어가는 길 / 리그 화면, 각자 작업본·고정 계약) → 갈래마다 독립 점검·고침 → 합침(첫 빌드에 통과).
4. 전체 검토(4 차원 + 찾은 것마다 반박 검증): 4건 중 3건 확인 — 고침
   - 릴이 상대를 카드 0.5초 전에 보여 주는데 잡힘은 카드 때라, 보고 B 로 빼서 공짜로 다시 뽑기 → 보인 순간 잡고 그 뒤 나감은 «나가기».
   - A 직후 홈(150ms 안)이면 뒤에서 찾기·카드·자동 대전이 돌아 못 본 상대가 잡힘 → 앱이 앞에 없으면 찾기를 안 연다.
   - 늦게 보인 파일 고침이, 못 읽는 파일이 남은 경우 기록을 매번 새로 만들었다(씨앗이 바뀌어 순위표가 끝없이 다시 불러짐) → 못 읽으면 막아 둠.
5. 마지막 고침 독립 확인: 진행 중
