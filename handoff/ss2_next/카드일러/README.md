# 카드 일러 — 찾았습니다

말씀대로 카드 모음집에 다 있었어요. 카드 모음집에 들어가서 올카드(소유 개수 120칸을 8로)로 채우니 «종류 120/960장»이 되고, 카드 120장이 모두 열립니다. 하나씩 열어서 앞면 그림이 어디서 오는지 따라갔습니다.

## 한 줄 결론

- 카드 그림은 **롬에 압축 없이** 들어 있습니다. 타일 바이트가 그대로 VRAM으로 복사됩니다.
- 카드는 120장인데 **그림은 60장**입니다. k0·k1이 한 그림, k2·k3이 또 한 그림을 같이 씁니다. 그래서 캐릭터 15명 × 유파 2 × 그림 2 = 60장입니다.
- 한 장은 **96×96 픽셀(12×12 타일)**이고, 타일은 75~144개, 팔레트는 8개까지 씁니다(팔레트마다 3색 + 투명).
- 롬 6판(순정 JUE, 한글 동봉판, ko101, h1, h1+ko101, h1+동봉)에서 **바이트가 모두 같습니다**. 한글 패치가 그림은 건드리지 않았어요.
- 별도 검증자가 자기 디코더로 처음부터 다시 풀고 에뮬레이터로 120장을 두 판에서 열어 봤는데 **240/240이 바이트 단위로 일치**했습니다. 판정은 «확인됨»입니다.

## 같은 그림이 나오는 곳

1. 카드 모음집 › 카드 보기 (15×8 격자 → A로 앞면)
2. 1인/무한 대전 캐릭터·유파 고른 뒤 «능력 추가» 카드 고르기 화면
3. 무한 대전 8연승 «카드 출현!!»
4. 1인 대전 엔딩 뒤 카드 공개 3장

네 곳 모두 같은 그림 객체를 씁니다. 카드 주기/받기(통신 교환)는 하네스에서 열리지 않아 못 봤습니다.

## 그림 내용 (말로만)

칸 순서는 수라 k01 / 수라 k23 / 나찰 k01 / 나찰 k23입니다. 대체로 **k01이 얼굴·상반신 초상**이고, k23은 동작 장면이 많습니다.

| 캐릭터 | 그림 | 초상으로 쓰기 좋은 것 |
|---|---|---|
| 카즈키 | 붉은 머리로 노려보는 얼굴 / 불꽃만 가득 / 짙은 붉은 머리 주먹 / 소리치는 얼굴 | 수라 k01 |
| 소게츠 | 푸른 머리 상반신 / 푸른 머리 동작 / 보라 머리, 손을 앞으로 / 보라 물결 | 수라 k01 |
| 하오마루 | 호리병 들고 씩 웃음 / 주먹 내밀며 고함 / 칼을 세운 정면 얼굴 / 칼을 어깨에 메고 미소 | 나찰 k01 |
| 겐쥬로 | 큰 술잔 들이킴 / 칼 든 얼굴 / 팔짱·곰방대 / 팔짱 | 수라 k23 또는 나찰 k01 |
| 나코루루 | 빨간 리본 상반신 / 매(마마하하)와 함께 / 보라 옷 상반신 / 늑대(시쿠루)와 함께 | 수라 k01 |
| 리무루루 | 나뭇잎 배경 상반신 / 얼음을 머리 위로 / 보라 옷 상반신 / 얼음 조각과 함께 | 수라 k01 |
| 한조 | 검은 큰 덩어리(가면 클로즈업)와 통나무 / 금빛 표창 / 뒷모습 / 가면 쓴 얼굴 | 나찰 k23 |
| 갈포드 | 포피와 함께 웃음 / 포피가 크게 / 칼 든 얼굴 / 번개 | 나찰 k01 |
| 아수라 | 회색 톤 두 장 / 붉은 머리·푸른 얼굴 두 장 | 나찰 k01 |
| 샬럿 | 갑옷 상반신 / 검 휘두름 / 금빛 갑옷 / 바람 소용돌이 | 수라 k01 |
| 모로즈미 | 붓 쥔 손 클로즈업 / 큰 붓글씨와 작은 몸 / 안경·초록 두건 얼굴 / 분홍 무기 | 나찰 k01 |
| 우쿄 | 푸른 머리 두 장 / 초록 머리 두 장 | 수라 k01 |
| 주베이 | 안대 얼굴(경단 생각 풍선) / 칼싸움 / 대나무·새와 생각하는 얼굴 / 칼을 멘 얼굴 | 수라 k01 |
| 시키 | 푸른 머리·붉은 눈 두 장 / 검은 머리 두 장 | 나찰 k01 |
| 유가 | 검푸른 머리 얼굴 / 손 뻗음 / 보라 얼굴 / 빛 폭발 | 수라 k01 |

초상으로 쓰기 어려운 그림은 카즈키 수라 k23(불꽃), 한조 수라 두 장, 한조 나찰 k01(뒷모습), 모로즈미 수라 k01(손), 유가 나찰 k23(빛)입니다. 쿠로코(ch 15)는 카드도 그림도 없습니다.

## 인게임 메뉴에 쓰려면

- 그림 바이트를 앱에 넣지 않고, **사용자가 고른 롬 파일에서 그 자리에서 읽어** 풀면 됩니다. 롬 주소 몇 개와 표 세 개만 따라가면 끝이고, 압축 풀기는 필요 없습니다.
- 한 장에 타일 144칸 이하, 팔레트 8개, 화면 96×96(160×152의 약 60% 폭)입니다. 덧판 창 층(타일 512)에는 넉넉히 들어갑니다. 다만 결판 화면이 이미 팔레트를 10~12개 쓰고 있어서, 그림 8개를 더하면 층 하나의 16개를 넘습니다. 그림 전용 층을 하나 두거나 팔레트 8칸을 그림 몫으로 비워 두는 게 좋겠습니다.
- 두 장을 나란히 놓으면 192px라 폭(160)을 넘습니다. 나란히 쓸 때는 가운데 8열(64×96)만 잘라 쓰면 됩니다(장당 타일 96 이하).
- 투명색(0)은 게임에서 흰색(0xFFF) 바탕으로 보입니다. 메뉴에서도 흰 판을 깔아 주면 원래 느낌이 납니다.
- 지금 기획서(157)에는 «롬 그림은 쓰지 않는다 · 게임 얼굴 그림은 쓰지 않는다»라고 되어 있어서, 쓰기로 하면 그 줄을 바꿔야 합니다.
