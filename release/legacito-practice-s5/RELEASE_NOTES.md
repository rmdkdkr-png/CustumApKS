# Legacito 시험판 — 연습 대전 1단계 s5 (2026-10-14)

`Legacito-practice-s5.apk` — s1~s4 와 같은 앱(패키지 `com.dudu.legacito.league`, 같은 서명)이라 덮어 설치하면 리그 기록·설정이 그대로 남습니다.
동봉 코어는 s4 와 같습니다(ss2-sp-core main 89860fe).

## 고친 것 (유저 보고)
- **비오의를 쓴 뒤 리셋해도 A+B 로 분노가 안 모이던 것** — 게임은 비오의를 쓰면 그 판 동안 A+B 분노 오르기를 막는데(0x5A55 bit7),
  연습 경기는 판이 끝나지 않아 영영 막혀 있었습니다. 이제 리셋(옵션+방향·메뉴의 리셋)하면 다시 A+B 로 분노를 터뜨릴 수 있습니다.
  맞아서 차는 분노는 원래부터 됐습니다.
- **아래 안내 띠가 패드를 가리던 것** — 게임 화면 아래에서 패드 버튼과 겹치지 않는 빈 줄에 놓입니다(버튼 배치를 바꿔도 피함).
  **손가락으로 끌어 옮길 수 있고** 그 자리를 기억합니다(세로·가로 따로). 두 번 톡 치면 기본 자리로 돌아갑니다.
- **연습 메뉴 창이 한 프레임 걸러 깜빡이던 것** — 특정 효과(샬럿의 기술 등) 뒤 게임이 화면 한쪽 띠의 가로 스크롤을 밀어 둔 채로 두면,
  메뉴 창이 그 띠에서 31px 밀려 깜빡였습니다. 창을 연 동안 두 띠 스크롤을 모두 제자리로 둡니다.
