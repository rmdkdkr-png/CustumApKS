앱 `NGPcustumSP-v1.1.18.apk` (versionCode 16010611, arm64-v8a·armeabi-v7a·x86·x86_64, 디버그 키 v1/v2/v3 서명).
1.1.x 위에 덮어 설치됩니다(같은 서명 키). **1.1.1~1.1.17 대신 이 판을 쓰십시오.**

## 동작 사이 그림(모션 캐시) 쓰는 법
1. 캐시 파일을 받습니다: https://github.com/rmdkdkr-png/PocketCore/releases/download/app/legacito-ss2-motion.bin (약 53MB, PocketCore 방이 공개).
2. 이름을 `ss2_motion.bin` 으로 바꿔 **세이브 파일이 있는 저장 폴더**나 **롬 파일 옆**에 둡니다.
3. 시스템 옵션 → 「프레임 생성 — 서기 자세」 그리기(기본), 「프레임 생성 — 동작 사이 그림」 캐시로 그리기(기본).
4. 롬을 열고 「버전 정보」를 보면 「모션 캐시 44438바뀜」처럼 나옵니다. 「없음」이면 파일 이름·자리를 확인하세요.

## 1.1.17 → 1.1.18
- **캐시가 실제로 쓰이게 됨** — 1.1.17 은 몸 포즈 지문 계산이 캐시를 만든 쪽과 달라 공개 캐시를 하나도 못 찾았습니다(사이 그림이 안 나옴).
  이제 PocketCore 쪽 기준 코어와 찾는 수·그리는 수가 같습니다.
- **사이 그림 결함 고침**(실제 대전 화면 792장을 검수해 확인된 37건 바탕):
  - 미리 본 프레임으로 확인 안 된 «다음 자세» 예측이 틀리면, 오지 않을 자세를 길게 붙들거나(최대 19프레임) 반대로 갔다 되돌아오던 것 —
    확인 전엔 반까지만, 예상 길이를 넘기면 멈춤.
  - 사이 그림이 상대의 발·창·타격 불꽃·머리 위를 덮던 것 — 지금 프레임의 겹침 순서를 따름.
  - 몸에서 떨어져 떠 있는 칼끝·팔 조각·한 칸 티끌 — 지움(원래 그림에 속도선 같은 떨어진 조각이 있는 포즈는 손대지 않음).
  - 위치가 20~40px 튀던 것·포즈 자리 1~4px 어긋남 — PocketCore 패치 99c 의 자리 보정.
- **원버튼 최속 발동**(PocketCore 패치 99c) — SP 키를 누르면 게임의 커맨드 입력 자리에 모션을 바로 써 넣어 필살기가 훨씬 빨리 나갑니다
  (그쪽 실측: 누르고 필살기까지 중앙 14→6 프레임, 15인·두 유파 76/76). 기본기 직후에는 게임이 받을 때까지 잠깐 기다렸다 넣습니다.
- 그대로인 것: 캐시가 없거나 「끔」이면 1.1.17 과 똑같이 동작합니다(코어 출력 바이트 동일 확인).
- 남은 것(캐시 내용 쪽, PocketCore 방에 전달): 반쯤에서 칼이 통째로 사라지거나 두 자루로 보이는 한 출력, 서기 순환에서 다음 자세가
  2프레임 일찍 통째로 보이는 경우.
