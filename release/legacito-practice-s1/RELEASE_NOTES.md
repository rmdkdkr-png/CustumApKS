# Legacito 시험판 — 연습 대전 1단계 (2026-10-14)

`Legacito-practice-s1.apk` — 패키지 `com.dudu.legacito.league`(가상 리그 시험판과 같음 · 시험 키). 리그 3단계 시험판 위에 덮어 설치하면 리그 기록을 그대로 잇고,
가상 리그(게임 속 «리그 대전»)도 그대로 들어 있다. 동봉 코어 = ss2-sp-core main 2cc0c59(99i~99p).

## 새로 된 것 — 연습 대전
- 런처 사무쇼2 카드 → 실행 창 **«연습 대전으로 ›»** → 상대 선택까지 저절로. 평소 «시작»으로 열어도 타이틀 셋째 줄이 **«연습 대전»**(순정 롬 «PRACTICE»).
- **상대 선택**: 15명(가운데 = 유가) · A 수라 더미 · B 나찰 더미 · 옵션 = 스테이지(오른쪽 세로 칸). 내 캐릭터는 원래대로(옵션 컬러 · B 2P색).
- **경기**: 시간 ∞ · 체력 바닥 64 와 자동 회복 · «2P» 표시 · 대미지 숫자.
- **연습 메뉴**(Option 짧게): 게임 PAUSE 위 창 — 더미(서기·CPU) · 가드(안 함·전부·첫 타 뒤·랜덤) · 내/상대 분노(보통·MAX) · 리셋 위치(가운데·왼쪽 벽·오른쪽 벽·지난 위치)
  · 리셋 좌우 · 숫자 · 지금 리셋 · 다시 고르기 · 타이틀로. ↑↓ 줄 · ←→ 값 · A 실행 · B/Option 닫기.
- **경기 중 리셋**: Option+↓(설정 위치) · Option+←/↑/→(왼쪽 벽/가운데/오른쪽 벽).
- 배경음악(사무쇼1 곡·끔)을 켠 채로도 켜진다. 옵션을 바꾸거나 이어하기·슬롯 불러오기를 해도 연습 경기가 그대로 이어진다.

## 그 밖에
- 120Hz 폰에서 가상 리그 허브가 프레임을 두 배로 세던 것도 같이 고쳐짐(코어 2배 출력의 합성 호출엔 안 돎).

## 확인
- 호스트: 롬 6판 연습 시험 68/68 · 이어가기 12/12 · 고침 7/7 · 리그 게임 속 흐름 28/28 · 배경음악 끔 사본 6판 68/68.
- 안드로이드 9 에뮬레이터(소프트웨어 CPU): 링크 → 상대 선택 → 경기 → 연습 메뉴 → 닫기 → 타이틀로 → 타이틀에서 다시 들어가기, 자동 저장이 있을 때 링크,
  슬롯 저장·불러오기, 옵션 바꾸고 이어하기. 조작감은 실제 폰에서 봐야 함.
