# NGPcustumSP 1.5.85-SS2-1.1.14 — 60Hz 사이 그림 (2026-10-11)

앱 `NGPcustumSP-v1.1.14.apk` (versionCode 16010607, arm64-v8a·armeabi-v7a·x86·x86_64, 디버그 키 v1/v2/v3 서명).
1.1.x 위에 덮어 설치됩니다(같은 서명 키). **1.1.1~1.1.13 대신 이 판을 쓰십시오.**

## 1.1.13 → 1.1.14
- **60Hz 사이 그림** — PocketCore 쪽 패치 90(9441b64)과 같은 내용(유저 「60Hz 도 넣어야지 … 4배 하던 거에서(2프레임 미리) 60 프레임에
  맞출 만한 노력만 하면 되잖어」). 사무쇼2는 캐릭터·배경이 2프레임마다(30Hz) 바뀌어 60Hz 화면에서도 움직임은 30Hz 였습니다.
  이제 120Hz 출력이 아닐 때(주사율 덮어쓰기를 안 했거나 화면이 60Hz)도 4배 예측의 2프레임 미리 돌리기를 그대로 써서 실제
  프레임마다 박자에 맞춘 자리를 그립니다 — 30→60Hz, 예측이라 지연 없음, 런어헤드와 같이 돕니다.
- 설정 「시스템 옵션 → 프레임 생성」이 세 값: **켬(기본)** = 120Hz 슬롯이 오면 120 출력, 아니면 60Hz 사이 그림 /
  **60Hz 사이 그림만** = 120 출력 없이(배터리) / **끔** = 런어헤드만. 옛 설정값(켬·끔)은 그대로 읽힙니다.
- 코어 쪽 확인(롬 600프레임): 120 출력은 1.1.13 코어와 1199장 바이트 동일. 60Hz 에서 바로 앞 장과 같은 출력 177 → 113장
  (64장이 반 자리 그림). 배관 130 검사, 합성 1635.

## 1.1.0 → 1.1.13 (포함)
- 포즈 교대 조각 어긋남 수정, 무리 강체, 자리 겹침 검증, 겉모습 짝짓기, 4배 게임 박자 맞춤, 몸·물체 위치 궤적 보간, 런어헤드,
  이펙트·장풍 옮기기/옮기기+섞기/끔, 감전·불탐 팔레트 몸 인식 + 몸 따로 박자, 날아가는 몸 포즈 섞기.

## 설정
120Hz 출력: 프레임 타이밍 옵션 → 화면 주사율 덮어쓰기 = 120Hz, 시스템 옵션 → 프레임 생성 켬(기본), 배수 4배(기본), 런어헤드 2(기본),
이펙트 옮기기(기본), 날아가는 몸 포즈 섞기(기본). 60Hz 화면이거나 배터리를 아끼려면 덮어쓰기 없이 「켬」 그대로(저절로 사이 그림)
또는 「60Hz 사이 그림만」.
