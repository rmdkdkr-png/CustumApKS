# NGPcustumSP 1.5.85-SS2-1.1.11 — 이펙트 옮기기 수정 (2026-10-10)

앱 `NGPcustumSP-v1.1.11.apk` (versionCode 16010604, arm64-v8a·armeabi-v7a·x86·x86_64, 디버그 키 v1/v2/v3 서명).
1.1.x 위에 덮어 설치됩니다(같은 서명 키). **1.1.1~1.1.10 대신 이 판을 쓰십시오.**

## 1.1.10 → 1.1.11
- **장풍이 뒤로 튀던 것 고침**(PocketCore 쪽 두 번째 판 0f42d23 과 같은 수정): 1.1.10 의 「이펙트 옮기기」는 장풍 근처에서
  가장 가까운 게임 물체 하나를 길잡이로 삼았는데, 옆을 지나는 캐릭터 그림자를 잡으면 장풍이 중간 그림에서 거꾸로 1~2px
  끌려갔습니다. 이제 장풍 그림이 감싸는 물체 모두 중 두 걸음 등속이면서 다음 그림과 가장 잘 맞는 것을 고르고, 몸과 같은
  자리에 붙어 다니는 물체(그림자)는 뺍니다. 몸에 붙은 이펙트도 앞 걸음·이번 걸음 둘 다 몸 이동과 맞아야 붙입니다.
- 「끔」은 1.1.9 와 똑같이 그립니다. 코어 쪽 확인(롬 600프레임): 끔 출력 전부 동일, 옮기기 19장 바뀜(맞음 불똥·별), 흩어진 조각 없음.
