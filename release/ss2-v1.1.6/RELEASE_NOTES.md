# NGPcustumSP 1.5.85-SS2-1.1.6 — 4배 게임 박자 맞춤 (2026-10-10)

앱 `NGPcustumSP-v1.1.6.apk` (versionCode 16010599, arm64-v8a·armeabi-v7a·x86·x86_64, 디버그 키 v1/v2/v3 서명).
1.1.x 위에 덮어 설치됩니다(같은 서명 키). **1.1.1~1.1.5 대신 이 판을 쓰십시오.**

## 1.1.5 → 1.1.6
- **프레임 생성 4배(게임 박자 맞춤)**: 사무쇼2는 캐릭터를 2프레임에 한 번(초당 30번), 배경 스크롤도 그 사이 프레임에
  2프레임에 한 번 움직입니다(롬 실측). 지금까지의 2배는 새 그림 사이 빈칸 셋 중 하나만 채웠습니다. 이제 실제 프레임
  직후 다음 두 프레임을 미리 돌려 캐릭터·배경 각각 「다음에 바뀌는 때」까지 고르게 나눠 120Hz 네 장 모두에 다른
  위치를 그립니다(점프 머리 높이 72→70→69→68 로 한 칸씩; 2배는 72,72→69,69→68). PocketCore 쪽 패치(023a638)를
  코어 main 에 들이고 같은 절차를 앱에도 넣었습니다. 에뮬 계산량은 2배 대비 약 1.5배.
- 설정 「시스템 옵션 → 프레임 생성 배수」: 4배(기본) / 2배. 빈 vsync 슬롯이 오는 동안(화면 120Hz)만 4배가 작동하고
  60Hz 에서는 날것 프레임 그대로입니다.
