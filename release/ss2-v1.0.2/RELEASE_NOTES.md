# NGPcustumSP v1.0.2 — 간다라 인식 정정

v1.0.1 의 버그 수정판입니다. 기능 추가는 없습니다.

## 고친 것

### 🗿 간다라를 못 알아보던 문제
간다라전인데 기둥에 엉뚱한 그림이 서고 해설도 간다라로 말하지 않던 문제를 고쳤습니다.

판별을 **보스 플래그**에 기대고 있었는데, 같은 간다라전이 플래그 1 로도 0 으로도
들어온다는 것이 제보 세이브로 드러났습니다. 제보하신 14장은 전부 플래그가 0 이라
하나도 걸리지 않았습니다. 이제 **개체 번호와 스테이지 두 값만으로** 가릅니다 —
실측 23장을 대조해 보니 이 조합이 간다라전에서만 나옵니다.

### 아수라 보스전을 간다라로 오인하던 문제
같은 판별표에 있던 「개체 8 + 보스기 = 간다라」 규칙이 오독이었습니다.
그 판은 **직전 장의 스테이지 6 보스전**이고 간다라는 그 다음 장에 나옵니다.
이제 로스터대로 제 이름을 부릅니다.
