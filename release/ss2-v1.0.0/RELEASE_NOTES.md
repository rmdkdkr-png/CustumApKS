# 사무라이 쇼다운!2 — SS2 커스텀판 v1.0.0

네오지오 포켓 명작 『사무라이 쇼다운!2』를 **한국어 실황 격투**로 바꾸는 커스텀 에뮬레이터, 첫 정식판.

## 이번 판의 얼굴

### 🏛 세로 일러 기둥
- 좌우 기둥에 **카드 대형 일러 15인 전원** — 2배 확대 세로샷, 캐릭터별 얼굴 초점 크롭
- 그림 데이터는 앱에 없다. **타일별 롬 주소표**만 싣고, 실행 중 당신의 롬에서 그린다
- 다음 상대가 정해지는 순간 기둥이 먼저 바뀐다

### 🎙 15인 캐릭터 해설 + 심판 쿠로코
- 하오마루부터 유가까지, 화자마다 제 말투로 싸움을 읽는다 — 상대 이름을 부르는 반응 ~750줄
- 심판 쿠로코: 대진 호명·팻말·구호 전부 한국어 안무
- 실플레이 세이브 93장 전수 검수: 컬렉션·카드·스토리 화면에선 조용하고, 싸울 때만 떠든다

### ⚡ 빠른 설정 오버레이
- **아래+옵션** 동시 누름 → 게임 화면 위에 설정창 (해설/해설자/심판/기둥/배경/진동/수집)
- B 또는 옵션으로 닫기. 게임엔 입력이 새지 않는다

### 🎮 원버튼 필살기 (ss2sp)
- SP+방향으로 기술이 나간다. 비오의는 뒤+A+B

## 설치
- ROM은 포함되어 있지 않다. 본인 소유 롬을 앱에서 열 것
- 스토어판 NGP.emu와 나란히 설치된다 (별도 앱 ID)
