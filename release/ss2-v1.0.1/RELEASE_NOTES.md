# NGPcustumSP v1.0.1 — 사무라이 쇼다운!2 한국어 해설 커스텀

네오지오 포켓 『사무라이 쇼다운!2』 전용 커스텀 에뮬레이터입니다.
NGPcustumSP는 Robert Broglia의 emu-ex-plus-alpha(NGP.emu)·Mednafen 코어를 기반으로 한
개조판이며, 원작 NGP.emu·NEO.emu(유료 앱)와는 별개의 앱입니다.

## 이번 판

### 🗿 간다라가 기둥에 섭니다
- 간다라전이 잡히면 우측 기둥에 **포효하는 간다라**(전투 인트로 실측)가 섭니다 —
  몸은 스크롤면, 얼굴은 스프라이트라 두 겹을 합성한 주소표입니다
- 다른 일러스트와 마찬가지로 그림 데이터는 앱에 없으며, 실행 중 사용자의 롬에서 그립니다

### 🎮 SP 기술 배치가 게임 안으로 들어왔습니다
- 빠른 설정(아래+옵션) 마지막 줄 → **SP 배치**: 캐릭터·유파를 고르고
  7슬롯(기본/→앞/←뒤/↓아래/↘/↙/공중)마다 **A 버튼으로 기술 목록에서 선택**합니다
- 커맨드는 화살표 표기(↓↘→+A), 공중기는 (공중) 표시, 기본 배치로 되돌리기도 있습니다
- **공중기 지상 발동**: 공중 전용기를 지상 슬롯에 두면 커맨드 뒤에 ↗+버튼을
  자동으로 넣어 저공에서 나갑니다 (타이거니 2369 자동화)
- B 버튼은 한 겹씩 돌아갑니다: 기술 고르기 → SP 배치 → 빠른 설정 → 닫기

### 💥 전황이 기둥에 실립니다
- **빠른 설정 = 일시정지** — 창이 열려 있는 동안 게임과 소리가 완전히 멈춥니다
- 맞은 쪽 기둥이 피해량에 비례해 **흔들리고**, 강타는 **하얗게 번쩍**입니다
- 빈사 상태면 붉게 물들고, KO 순간 진 쪽은 흑백이 됩니다
- 일러스트 변형 4종: 기둥에 설 때 랜덤으로 1장을 정하며, 얼굴 초점 60장을 수동으로 확정했습니다

### 📇 그 밖에
- **앱 이름 NGPcustumSP** + 시스템 설정 「버전 정보」 항목 + 새 아이콘(게임 내 글꼴)
- **SS2 전용 잠금**: 다른 롬은 열리지 않습니다 — 범용 에뮬레이터로 쓰여 원작자
  유료 앱의 이익을 침해하지 않기 위해서입니다
- 해설 정정: 같은 기술 3연속 적중은 「상대가 못 읽는」 방향으로 말하고,
  나코루루는 언제나 상냥한 나코루루로 말합니다
