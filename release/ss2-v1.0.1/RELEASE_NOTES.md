# NGPcustumSP v1.0.1 — 사무라이 쇼다운!2 한국어 해설 커스텀

네오지오 포켓 『사무라이 쇼다운!2』 전용 커스텀 에뮬레이터.
NGPcustumSP — Robert Broglia의 emu-ex-plus-alpha(NGP.emu)·Mednafen 코어 기반 개조판이며,
원작 NGP.emu·NEO.emu(유료 앱)와는 별개다.

## 이번 판

### 🗿 간다라가 기둥에 선다
- 간다라전이 잡히면 우측 기둥에 **포효하는 간다라**(전투 인트로 실측) —
  몸은 스크롤면, 얼굴은 스프라이트라 두 겹을 합성한 주소표다
- 다른 일러와 마찬가지로 그림 데이터는 앱에 없고, 실행 중 당신의 롬에서 그린다

### 🎮 SP 기술 배치가 게임 안으로
- 빠른 설정(아래+옵션) 마지막 줄 → **SP 배치**: 캐릭터·유파 골라
  7슬롯(기본/→앞/←뒤/↓아래/↘/↙/공중)마다 **A로 기술 목록에서 선택**
- 커맨드는 화살표 표기(↓↘→+A), 공중기는 (공중), 기본 배치로 되돌리기 포함
- **공중기 지상 발동**: 공중 전용기를 지상 슬롯에 두면 커맨드 뒤 ↗+버튼을
  자동으로 넣어 저공에서 나간다 (타이거니 2369 자동화)
- B는 한 겹씩 복귀: 기술 고르기 → SP 배치 → 빠른 설정 → 닫기

### 💥 전황이 기둥에 실린다
- **빠른 설정 = 일시정지** — 창이 열려 있는 동안 게임·소리 완전 정지
- 맞은 쪽 기둥이 피해량 비례로 **흔들리고**, 강타는 **백섬광**
- 빈사면 붉게 물들고, KO 순간 진 쪽은 흑백
- 일러 변형 4종: 콜될 때 랜덤 1장, 얼굴 초점 60장 수동 확정

### 📇 그 밖에
- **앱 이름 NGPcustumSP** + 시스템 설정 「버전 정보」 란 + 새 아이콘(게임 내 글꼴)
- **SS2 전용 잠금**: 다른 롬은 열리지 않는다 — 범용 에뮬로 쓰여 원작자
  유료 앱의 이익을 침해하지 않게
- 해설 정정: 같은 기술 3연속은 「상대가 못 읽는」 방향으로, 나코루루는 언제나
  상냥한 나코루루로
